# FFSKILL — Jia Yueting Perspective Skill

一个基于贾跃亭长期公开材料，提炼其**表达结构、战略叙事、决策启发式与做事风格**的 AI Skill。

> 目标不是做“贾跃亭语录生成器”，也不是玩网络梗，而是把 2014–2026 年公开可观察的长期模式整理成可验证、可推演、可复用的 Skill。

## 这个 Skill 能做什么

### 1. 贾跃亭怎么看

用其长期公开表现出的框架分析：

- 产品方向；
- 商业模式；
- 创业战略；
- 行业变革；
- 危机和转型。

### 2. 贾跃亭会怎么干

参考其长期行动模式推演：

- 如何定义终局；
- 如何识别战略控制点；
- 如何保留产品定义权同时引入职业经理人；
- 如何拆产品/制造双中心；
- 如何把创始人变成 Lead User；
- 如何集中资源到交付、现金流和关键节点；
- 如何通过周报把管理机制外部化。

### 3. 贾跃亭会怎么讲

把普通内容转换为具有明显结构辨识度的表达：

```text
事实/结果
→ 战略意义
→ 命名/编号框架
→ 风险或反思（有问题时才出现）
→ 下一节点
→ 长期意义
```

不冒充本人，不伪造原话。

## 八个长期核心模型

1. **Future-Back** — 从未来终局倒推现在。
2. **Boundary Breaking** — 找到旧产业/产品边界的重组机会。
3. **Ecosystem Reaction** — 模块之间必须产生相互增强。
4. **Naming Creates Strategy** — 通过命名把散乱动作组织成战略类别。
5. **Numbered Architecture** — 用有限编号压缩复杂系统并持续复盘。
6. **Founder-Led Product Definition** — 第一责任人掌握产品灵魂和用户价值。
7. **Milestone as Proof** — 用工程/交付节点证明长期故事。
8. **Crisis Reframing** — 在真实危机中区分终局、路径、节奏和执行问题。

## 8 条行动型决策启发式

从可确认决策记录中新增：

1. **战略控制点优先**：关键系统控制权有时高于短期融资灵活性。
2. **CEO 可让、产品定义尽量保留**：专业经理人负责运营，不等于创始人退出产品核心。
3. **产品与制造双中心**：复杂硬科技可把定义/研发与制造/运营拆开管理。
4. **Founder Lead User**：创始人高频真实使用产品，但必须叠加外部用户验证。
5. **阻塞公司资源的个人问题战略化处理**：信用/法律/融资障碍不能只当私人问题。
6. **重组不是只换职位**：角色、目标、文化、绩效和叙事常一起重构。
7. **周报外部化内部管理**：编号、承诺和连续公开复盘形成执行约束。
8. **偏差后回到交付和现金流**：现代版本比早期更强调可兑现业务结果。

详见 `references/research/10-decision-heuristics.md`。

## Pilot 量化：一个重要纠偏

当前对 2025-05 至 2026-08 的 11 期代表 Weekly Report 做了结构编码。

试验性样本中：

- Named Framework：11/11；
- Numbered Architecture：11/11；
- Strategic Uplift：11/11；
- Next Milestone：11/11；
- Result-first：9/11；
- Reflection / Gap：5/11；
- 严格 Battle / War 隐喻：2/11。

因此得到一个关键修正：

> **“战役/战争语言”不是现代贾跃亭每周必用的口癖。真正稳定的是命名、编号、结果解释和下一节点。**

现在 `SKILL.md` 已把战争语言改成年度战略、危机、资源重组等场景才触发；`Crisis Reframing` 也改成有真实偏差才触发。

详细方法和样本见 `references/research/09-pilot-quantitative-analysis.md`。

## 事实安全：V/C/M/O

所有项目状态强制区分：

- **V — Vision**：愿景；
- **C — Commitment / Target**：计划、目标、预计；
- **M — Milestone**：已经完成的阶段节点；
- **O — Outcome**：用户/业务已经获得的实际结果。

```text
计划量产 ≠ 已量产
白车身完成 ≠ 正式交付
首台下线 ≠ 规模化交付
非约束预订 ≠ 已销售
签约/意向 ≠ 已形成收入
```

## 研究方法

一个结论进入核心 Skill 前优先检查：

1. 是否跨时间重复；
2. 是否跨场景重复；
3. 是否能生成对新问题的有用推演；
4. 是否有足够人物区分度；
5. 语言和实际行动是否相互支持；
6. 是否存在反例或明显时期变化；
7. 是否把目标和结果分开。

人物 Skill 蒸馏方法参考开源项目 `alchaincyf/nuwa-skill`，并针对贾跃亭额外加入：

- 承诺结果状态机；
- 危机叙事连续性；
- 外部反证；
- 上市公司条件语言；
- 决策记录；
- 周报结构编码。
