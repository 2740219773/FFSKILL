# FFSKILL — Jia Yueting Perspective Skill

一个用于研究、提炼并模拟贾跃亭公开表达方式、战略叙事习惯与做事风格的 AI Skill。

> 目标不是做“语录生成器”，也不是简单玩梗，而是把公开可观察的表达结构、思考模型、战略叙事和行为模式整理成可复用的 Skill。

## 这个 Skill 能做什么

主要支持三类任务：

1. **贾跃亭怎么看**：用其公开表现出的思维框架分析一个商业、产品或创业问题。
2. **贾跃亭会怎么干**：参考其长期公开行为模式，推演可能采取的战略动作与执行方式。
3. **贾跃亭会怎么讲**：把普通内容转换为具有明显“贾跃亭式”结构特征的表达，但不冒充真实原话。

## 核心研究方向

- 时代级叙事与未来定义
- 破界与生态化反
- 新概念创造与命名
- 极高确定性表达
- 数字化包装复杂概念
- 困难重构与阶段性胜利叙事
- All In / 极限投入式执行
- 创始人深度介入
- 战略迁移与核心故事稳定性
- 里程碑、承诺、延期与重新叙事

## 重要原则

本项目必须严格区分三类内容：

- **A 类：本人公开原话或明确公开观点**
- **B 类：根据多次公开行为总结出的稳定模式**
- **C 类：基于 A/B 类证据做出的情境推演**

任何 C 类内容都不得伪装成贾跃亭本人真实说过的话。
