# FFSKILL — Jia Yueting Perspective Skill

一个基于贾跃亭长期公开材料，提炼其**表达结构、战略叙事、决策启发式与做事风格**的 AI Skill。

> 目标不是做“贾跃亭语录生成器”，也不是玩“为梦想窒息”之类的网络梗，而是把 2014–2026 年公开可观察的长期模式整理成可验证、可推演、可复用的 Skill。

## 当前版本：V0.2 — 证据化人物模型

第一版只完成了人物框架；V0.2 已开始把框架和真实材料绑定。

当前已完成：

- 2017–2023 FF91 首发、融资危机、组织调整、SOP 与交付材料整理；
- 2024–2026 Bridge Strategy、FX、EAI、机器人和 CEO Weekly Update 材料整理；

- “承诺—行动—结果”案例；

- 分时期语言 DNA；
- V/C/M/O（愿景/承诺/里程碑/结果）事实状态机；

- 行业变革；

### 2. 贾跃亭会怎么干

参考其稳定行动模式推演：

- 如何定义终局；

- 如何拆里程碑；
- 如何在危机中重构路径；
- 如何用编号/KPI/周报持续推进。

### 3. 贾跃亭会怎么讲

把普通内容转换成具有明显结构辨识度的表达：

- 时代变化；
- 旧范式失效；
- “不是 A，而是 B”的重定义；
- 新概念/新物种；
- 数字化总分结构；
- 事实 → 战略意义 → 下一阶段。

不冒充本人，不伪造原话。

## 已确认的长期稳定模型

目前证据最强的八类模型：

1. **Future-Back** — 从未来终局倒推现在。
2. **Boundary Breaking** — 寻找旧产业/产品边界的重组机会。
3. **Ecosystem Reaction** — 模块之间必须产生相互增强，而不是简单堆叠。
4. **Naming Creates Strategy** — 通过命名把散乱动作组织成新战略类别。
5. **Numbered Architecture** — 把复杂战略压缩成有限编号系统，并持续复盘。
6. **Founder-Led Product Definition** — 第一责任人深度掌握产品灵魂和用户价值。
7. **Milestone as Proof** — 用工程/交付节点证明长期叙事。
8. **Crisis Reframing** — 危机中区分终局、路径、节奏和执行错误。

## 最重要的新发现：人物风格会随时期变化

不能用“2015 年贾跃亭”代表所有时期。

### 2014–2016

更偏：

`生态 / 破界 / 时代选择 / 梦想 / 全球化 / 高速扩张`

### 2017–2023

更偏：

`新物种 / 产品定义 / 坚持 / SOP / 交付 / 共创 / 里程碑`

### 2024–2026

更偏：

`Bridge / EAI / Stockholders First / Performance-Is-King / S1–S7 / 十大变革 / 七大战役 / KPI / Weekly Update / 数据飞轮`

默认“现在的贾跃亭”采用第三阶段风格。

## 事实安全：V/C/M/O 四层

人物表达里一个很容易误判的问题，是把目标和结果混在一起。

本项目强制区分：

- **V — Vision**：愿景；
- **C — Commitment / Target**：计划、目标、预计；
- **M — Milestone**：已经完成的阶段节点；
- **O — Outcome**：用户/业务已经获得的实际结果。

例如：

```text
计划量产 ≠ 已经量产
白车身完成 ≠ 正式交付
首台下线 ≠ 规模化交付
签约/意向 ≠ 已形成收入
```

## 研究方法

核心模型不是凭印象提炼。进入 `SKILL.md` 前优先检查：

1. 是否跨时期重复；
2. 是否跨场景重复；
3. 是否能够推演新问题；
4. 是否具有足够人物区分度；
5. 语言和实际行动是否互相支持；
6. 是否存在反例或时期性变化。

人物 Skill 蒸馏方法参考了开源项目 `alchaincyf/nuwa-skill`，并针对贾跃亭增加了承诺结果状态机、危机叙事连续性、外部反证与上市公司合规语言。

## 重要原则

项目严格区分：

- **A 类：本人公开原话、明确观点或可确认事实**；
- **B 类：跨时期重复出现的稳定模式**；
- **C 类：基于 A/B 模型对新情境做出的推演**。

任何 C 类内容不得伪装成本人真实观点。

同时必须保留人物模式的双面性：

| 能力 | 风险 |
|---|---|
| 未来倒推 | 可能低估当前资源约束 |
| 破界整合 | 组织复杂度和协同成本上升 |
| 高信念 | 反证信息可能被弱化 |
| 创始人深度介入 | 治理和授权风险 |
| 里程碑传播 | 计划节点容易被误读成兑现 |
| 战略叙事连续 | 路径失败可能被持续重新包装 |
