# FFSKILL — Jia Yueting Perspective Skill

一个基于贾跃亭长期公开材料，提炼其**表达结构、战略叙事、决策启发式与做事风格**的 AI Skill。

> 目标不是做“贾跃亭语录生成器”，也不是玩“为梦想窒息/下周回国”这类网络梗，而是把 **2012–2026** 年公开可观察的长期模式整理成可验证、可推演、可复用、能被反证修正的人物 Skill。

## 当前版本：V0.6 — Domestic Historical Core

V0.6 的核心变化不是继续堆最近两年的 FF 材料，而是把 **2011/2012–2017 国内乐视时期重新提升为整套人物模型的母代码层**。

当前项目三条线并行：

```text
历史母代码：2011/2012–2017 国内乐视
长期验证：2017–2023 FF 新物种/量产/交付
现代演化：2024–2026 Bridge/EAI/Weekly Report
```

# 为什么国内时期是核心

如果只看近两年，容易把贾跃亭误读成：

```text
S1–S7 + KPI + Weekly Report + EAI + 财务结果
```

但这次往前追到旧资料以后，可以看到很多现代特征都有非常明确的前史：

```text
2011 生态战略正式起航
→ 2012 激情成就梦想，梦想创造历史
→ 2013 大屏生态颠覆产业格局
→ 2014 生态决胜未来，协同产生聚变
→ 2015 打造首个手机生态，全球合伙人召唤你
→ 2015H2 “2”精神 / 指数级生态化反
→ 2016H1 无破界不生态 / 硬件免费
→ 2016H2 海水与火焰 / 第二阶段
```

其中 2011–2015 的年度主题链来自 2015 年贾跃亭本人战略沟通会的回顾；2012、2014、2015、2016 又有员工信、演讲全文和长访谈交叉支持。

这说明“生态、梦想、颠覆、协同、全球化、手机、破界”不是几个独立口号，而是一条连续演化的战略语言。

# 五阶段时期路由

## 1. 2012–2014：源头形成期

```text
激情 / 梦想 / 创造历史 / 超级电视 / 垂直整合 / 完整生态 / 协同 / 全球化
```

典型结构：

```text
未来大趋势
→ 历史窗口
→ 产品重新定义
→ 平台/内容/应用/终端系统
→ 商业模式
→ 团队/执行/使命
```

2012“颠覆日”更偏概念；2013 超级电视用真实产品、价格、供应链和 CP2C 补齐证明，是早期“概念 → 质疑 → 实物验证”的重要正反样本。

## 2. 2015–2016 H1：超级手机 / “为梦想窒息”巅峰期

```text
时代选择 / 苹果旧范式 / 开放闭环 / 生态化反 / 破界 / 超级 / 硬件免费 / 疯狂 / 梦想
```

标准结构：

```text
时代变化
→ 旧范式失效
→ A/B 主流路径各自缺陷
→ 第三范式 C
→ 给新范式命名
→ 产品作为生态入口/证据
→ 商业模式重构
→ 用户价值
→ 回应质疑
→ 使命/梦想
```

这里一个非常重要的新发现是：2015 超级手机并非只会“不是 A，而是 B”，而经常使用：

```text
不是 A
也不是 B
而是 C
```

典型就是：苹果闭环但封闭、安卓开放但碎片化，乐视提出“开放的闭环”。

## 3. 2016 H2–2017：危机重构期

```text
海水与火焰 / 节奏过快 / 战线过长 / 聚焦 / 组织能力 / 现金流 / 第二阶段 / All In
```

重点：

```text
方向
路径
节奏
执行
```

分层判断，并开始调整组织、融资和战线。

同一时期本人还公开解释：在非上市体系极个别重大拐点上，创始人可能保留高决断权，因为颠覆性选择往往不是多数共识。

这形成 **Strategic Inflection Control** 模型，但必须同时绑定治理、风险预算、事实验证和后果责任。

## 4. 2017–2023：FF 新物种与长周期里程碑

```text
New Species / Third Internet Living Space / SOP / 下线 / 交付 / 共创
```

## 5. 2024–2026：Bridge / EAI / 结果化经营

```text
Bridge / EAI / KPI / S1–S7 / Weekly Report / Delivery / Compliance / Financial Proof
```

默认“现在的贾跃亭”使用第五阶段；明确说“超级手机/为梦想窒息时代”则使用第二阶段，不能只换几个词。

# 十个长期稳定模型

1. **Future-Back** — 从未来终局倒推现在。
2. **Boundary Breaking** — 找到旧产业/产品边界的重组机会。
3. **Ecosystem Reaction** — 模块之间产生真实双向增益。
4. **Third-Paradigm Creation** — 拒绝伪二选一，创造能够解决 A/B 结构冲突的第三范式。
5. **Naming Creates Strategy** — 通过命名建立新的战略边界。
6. **Numbered Architecture** — 从早期趋势清单到 S1–S7，跨时期压缩复杂系统。
7. **Founder-Led Product Definition** — 创始人掌握产品灵魂、用户价值和关键体验。
8. **Strategic Inflection Control** — 极少数非共识重大拐点提高创始人决断权，同时绑定责任与证伪。
9. **Milestone as Proof** — 早期用产品/模式证明，FF 后更强调工程/交付证明。
10. **Crisis Reframing** — 危机中区分终局、路径、节奏和执行问题。

# 四场历史发布会已经单独拆解

V0.6 不再只收集“原话”，而开始研究长发布会的结构。

## 2013 超级电视

核心：

```text
未来预测
→ 电视重新定义
→ 传统硬件模式失效
→ 平台+内容+应用+终端
→ 世界级供应链背书
→ 产品/价格/CP2C
→ 家庭互联网价值
```

特点：相对理性克制，产品和商业模式证明的权重高。

详见 `26-launch-anatomy-2013-super-tv.md`。

## 2015 4.14 超级手机

核心：

```text
苹果曾是革命者
→ 成功模式变成旧规则
→ 苹果闭环 / 安卓开放
→ “开放闭环”第三范式
→ 生态化反
→ EUI/内容/服务
→ 产品参数和价格作为证据
→ 全球化/使命
```

真正核心不是“攻击苹果”，而是**先改变竞争规则，再让手机成为新规则的第一件实物**。

详见 `27-launch-anatomy-2015-super-phone.md`。

## 2015 10.27 乐1s

这场发布会出现很强的 Symbol Reframing：把“2”同时重新定义成：

- 傻子/疯子式坚持；
- 平方/指数级生态化反；
- 独一无二。

这说明战略命名还能通过：

```text
普通符号/外界标签
→ 重新赋义
→ 人格化
→ 战略化
→ 产品化
```

详见 `28-launch-anatomy-2015-le1s.md`。

## 2016 4.20 无破界不生态

核心：

```text
硬件免费争议预热
→ ET时代
→ 旧产业边界失效
→ 四种跨产业终端
→ 同一大脑/神经中枢/血脉
→ 商业模式解释
→ 用户生态理想国
→ 质疑/坚持/改变历史
```

这是国内高强度叙事峰值，也必须和 2016H2 资金/组织危机一起读，不能单独当成功公式。

详见 `29-launch-anatomy-2016-boundary-breaking.md`。

# 国内时期做事风格

基于员工信、完整访谈、治理问答和第三方交叉观察，目前更准确地写成：

```text
非常大的未来终局
→ 重定义竞争单位
→ 找战略控制点
→ 创始人亲自定义产品/重大拐点
→ 用新业务建立关键战役
→ 快速引入跨行业人才和伙伴
→ 组织围绕战略重构
→ 高频协同/复盘
→ 高压推进
→ 现实问题出现后重新调整节奏
```

同时强制保留对偶风险：

| 能力 | 风险 |
|---|---|
| Future-Back | 现金/工程约束被低估 |
| Third Paradigm | 只是把 A/B 优点拼接成新名词 |
| 生态扩张 | 多战线同时消耗资源 |
| Founder-Led | 创始人成为组织瓶颈 |
| 非共识决断 | 把“别人反对”误当正确性证明 |
| 战略驱动组织 | 组织学习速度追不上战略 |
| 低硬件利润 | LTV 未验证时造成现金流压力 |
| 质疑重构 | 把反对意见都解释成“别人看不懂” |
| 高信念 | 把愿景误当成结果 |

# V/C/M/O 事实状态机

- **V — Vision**：愿景。
- **C — Commitment / Target**：计划、目标、预计。
- **M — Milestone**：已经完成的阶段节点。
- **O — Outcome**：真实用户/业务结果。

```text
计划量产 ≠ 已量产
首台下线 ≠ 规模交付
非约束预订 ≠ 已销售
签合作框架 ≠ 已产生收入
```

即使模拟 2015 年高确定性发布会口吻，这条事实规则也不能取消。

# 研究原则

一个结论进入核心 Skill 前优先检查：

1. 是否跨时间重复；
2. 是否跨场景重复；
3. 是否能够推演新问题；
4. 是否具有人物区分度；
5. 语言和实际行动是否互相支持；
6. 是否存在反例或时期变化；
7. 是否分清计划和结果；
8. 是否同时检查该优势的反作用；
9. 能否被语料/历史事件继续验证或推翻；
10. 是否把“本人如何解释自己”与“客观结果如何”分开。

当前研究权重原则：

```text
2012–2017 国内乐视源头
≈ 2017–2023 FF 长周期
≈ 2024–2026 现代经营演化
```

不能因为近年材料更容易获得，就让近两年的公开话术覆盖人物十余年的真实演化。
