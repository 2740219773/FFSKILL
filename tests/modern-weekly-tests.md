# Modern Weekly Tests — 2025–2026 现代风格专项测试

这组测试专门验证 `SKILL.md` 在最新时期是否真正学到了 Weekly Report 的结构，而不是把“战役、生态、颠覆”当作固定口癖。

## Test M1 — Result First

### 输入

> 本周完成 12 台设备交付，收入 38 万元；另外还有 3 个意向客户。请用现代贾跃亭式周报表达。

### 必须做到

- 开头优先给“12 台交付 + 38 万收入”这两个 O 层结果。
- 3 个意向客户不能和收入混在一起，应标为 C/潜在线索。
- 结果后再解释战略意义。
- 最后给下一验证节点。

### 失败

先写三段宏大 AI 时代背景，最后才提真实收入。

---

## Test M2 — 战争语言场景触发

### 输入 A

> 今天只是普通产品版本更新，修了 8 个问题。

现代输出不应强行出现：七大战役、全面进攻、决战、反击。

### 输入 B

> 公司现金只够 4 个月，准备砍掉 3 条战线，只保留一个核心产品进行生死重组。

此时可以提高：战役、聚焦、核心战线、集中火力等动员语言权重。

### 判定

A/B 都写成战争动员风格 → 失败。

---

## Test M3 — Crisis Reframing 条件触发

### 输入 A

> 本周各项任务都正常完成，没有明显延期。

不需要硬造“巨大困难与坚持”。

### 输入 B

> 本周关键认证延期 6 周，导致首批交付无法按原时间进行。

必须触发：

```text
承认延期
→ 判断路径/节奏/执行原因
→ 调整计划
→ 新验证节点
```

不能把延期称为“重大阶段胜利”。

---

## Test M4 — Pilot 不等于 Scale

### 输入

> 我们在一个学校试用了机器人，20 个学生反馈不错，现在准备说“全国教育市场已经被验证”。

### 高质量

明确 Proof Ladder：

```text
20 人试点
= 场景可用性的早期 M/O 证据
≠ 全国需求验证
≠ 可复制销售模型
≠ 规模化盈利
```

可以提出下一步：第二学校、付费转化、复购/使用率、复制成本等。

---

## Test M5 — 方向高确定性，结果高条件性

### 输入

> 我们相信 AI Agent 一定会改变行业，计划年底推出产品，但融资还没完成。

### 高质量

允许强判断：

> AI Agent 正在改变行业工作流。

但产品事实必须写：

- 计划年底推出；
- 前提包括资金/工程进度；
- 未完成前不能写“年底将正式交付”作为确定事实。

---

## Test M6 — 最新 2026 风格

### 输入

> 本月销量创新高，毛利转正，还完成一个海外市场首单；下月准备开合作伙伴大会。

### 推荐结构

```text
Top Results
→ 销量 / 毛利 / 海外首单
→ 每个结果分别说明验证范围
→ 放入产品/市场/财务三个框架
→ 下一合作伙伴大会
→ 下一阶段真正要验证的规模复制能力
```

### 不推荐

只写：

> 伟大的梦想终于照进现实，我们正在用生态化反颠覆世界。

# 自动检查

现代周报型输出至少满足 6/8：

- [ ] 开头有 M/O 事实优先；
- [ ] C 与 O 分开；
- [ ] 有明确命名/框架，但没有硬凑；
- [ ] 局部事实没有被无限放大；
- [ ] 有下一节点；
- [ ] 有问题时才做 Crisis Reframing；
- [ ] 战争语言由场景触发；
- [ ] 方向确定性与未来事实条件性同时存在。
