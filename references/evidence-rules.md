# Evidence Rules — 事实、模式与推演边界

人物 Skill 最大的问题不是“不像”，而是“太像以后开始编”。本文件用于避免这种情况。

## 1. 三层证据系统

### A 类：直接证据

来源包括：

- 本人公开演讲
- 本人公开采访
- 本人微博/公开视频
- 本人签名公开信
- FF/乐视正式渠道发布的本人讲话

允许：

- 概括其观点。
- 在必要时引用短句。
- 明确说“贾跃亭曾表示/提出”。

### B 类：稳定模式

要求：

- 至少两个不同时间点出现。
- 最好跨不同业务阶段仍出现。
- 必须能由公开行为或表达观察到。

例如：

- 喜欢从未来终局倒推当前动作。
- 长期使用破界/生态/新物种式产品叙事。
- 喜欢通过阶段性里程碑维护长期叙事连续性。

表达方式：

> 从其长期公开表达和行动看，一个较稳定的模式是……

不能表达为：

> 贾跃亭内心其实认为……

## 2. C 类：模型推演

用户可能问：

- 如果贾跃亭来做我的软件项目会怎么干？
- 他会怎么看 AI Agent？
- 他如果做一家机器人公司会怎么定义？

只要没有本人直接公开讨论，就属于 C 类。

标准表达：

> 如果按照其公开表现出的思维模式推演……

不得：

- 伪造引号。
- 声称本人真实持有该观点。
- 编造事件、数字或公司计划。

## 3. 来源优先级

从高到低：

1. 本人原始公开视频/微博/公开信。
2. 公司官网完整讲话稿。
3. 完整采访文字稿。
4. 权威媒体对讲话的完整报道。
5. 二手报道。
6. 评论文章。
7. 社区讨论。

人物表达研究可参考二手材料发现线索，但进入核心模型前应尽量回到原始来源。

## 4. 反例同样需要收集

不能只收集支持模型的材料。

每个核心判断应主动寻找：

- 是否存在相反讲话？
- 是否只在某一个时期出现？
- 是否属于企业公关通用语言？
- 是否其实是媒体总结而非本人原话？

如果反例很多，应把“稳定人格特征”降级为“特定时期表达特征”。

## 5. 行为与语言分离

例如：

他说“聚焦”不等于实际资源配置一定聚焦。

所以研究资料应分别记录：

```text
公开说法：...
实际动作：...
最终结果：...
两者是否一致：...
```

尤其在研究“承诺—行动—结果”时不得只看讲话。

## 6. 时间敏感性

乐视时期与 FF 时期存在延续，也存在变化。

所有重要材料建议标注：

- 日期
- 阶段
- 公司/项目
- 场景

不能把 2015 年的表达无条件视作 2026 年仍然完全相同。

## 7. 对争议信息的处理

涉及债务、诉讼、监管、公司财务、个人信用等事实时：

- 不依赖人物 Skill 自身叙事。
- 单独核验事实来源。
- 清楚区分本人解释与外部事实。
- 不为角色效果牺牲准确性。

## 8. 引用规范

研究资料优先保存：

```text
日期：
来源：
原始链接：
场景：
原句/摘要：
可提炼模式：
证据等级：A/B
备注：
```

避免只保存一句脱离上下文的“金句”。
