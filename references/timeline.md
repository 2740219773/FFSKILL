# Timeline — 战略、表达与行动演化时间线

这不是人物传记，而是用于追踪“说法—行动—结果—叙事变化”的研究时间线。

## 2014 — SEE：汽车不是单一硬件

- 12 月：公开 SEE 计划。
- 关键词：移动互联网、汽车产业革命、垂直整合、重新定义汽车、汽车互联网生态。
- 稳定模式起点：**先定义行业未来，再宣布产品计划。**
- 来源：https://www.chinanews.com/cj/2014/12-10/6861401.shtml

## 2015 — 生态战略成为完整世界观

- 1 月：年度战略将未来十年、中国企业全球化、产业互联网连接起来。
- 5 月长访谈：强调互联网时代产业边界模糊，生态路线是“时代选择”。
- 关键词：时代选择、垂直整合、边界模糊、全球化、堂吉诃德。
- 变化：从“公司商业模式”升级成“新旧时代规律”。
- 来源：https://paper.people.com.cn/hqrw/html/2015-05/06/content_1631010.htm

## 2016 H1 — “破界”进入产品发布语言

- 4 月“无破界不生态”发布会，把手机、电视、VR、汽车等统一到生态叙事。
- 关键词：破界、流动、生态化反、生态理想世界。
- 模式：**多个业务不是并列，而是要解释彼此怎样产生新增价值。**

## 2016 H2 — 全球化顶峰与资金危机

- 9–10 月：汽车融资、美国生态落地，仍强调投入未来和全球验证。
- 11 月：《乐视的海水与火焰》承认节奏过快、全球战线过长、资金与供应链压力。
- 调整：告别一味烧钱扩张，强调经营、盈利、组织效率。
- 不变：生态方向没有被整体否定。
- 研究意义：形成典型 Crisis Reframing：**愿景保留，路径和节奏重构。**
- 来源：https://www.eeo.com.cn/2016/1106/293722.shtml

## 2017-01 — FF91 首发，“新物种”迁移成功

- FF 91 CES 首发。
- 关键词：new species、reformat future of mobility。
- 产品：性能、豪华、互联网、智能功能被组合为新类别。
- 计划：当时官方材料写生产计划 2018 启动。
- 来源：https://www.ff.com/us/press-room/ff-91-press-release/

## 2017-01 — 生态控制权与资本决策

- 研究意义：生态理念不只存在于发布会，而会进入股权/控制权取舍。
- 来源：https://www.yicai.com/news/5205432.html

# 长周期总结

从 2014 到 2026 年 8 月，载体变化极大，但以下结构持续存在：

```text
未来趋势
→ 旧边界失效
→ 重新定义问题
→ 创造新物种/新概念
→ 生态协同
→ 集中资源
→ 里程碑证明
→ 把阶段结果升级为下一阶段
```

变化最明显的是表达和管理工具：

```text
2014–2016：梦想 / 生态 / 破界 / 全球化
2017–2023：新物种 / 坚持 / 里程碑 / 共创
2024–2025：Bridge / EAI / 股东优先 / 战役 / KPI / 周报
2026 H2：Result-First / Revenue / Gross Margin / Compliance / Campaign / Data Flywheel / Event Chain
```

因此 Skill 必须支持“时期感”，不能用一套 2015 年词汇覆盖全部时间。
