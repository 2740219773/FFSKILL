# Research 06 — 承诺、行动与结果案例

本文件专门避免人物 Skill 的一个常见错误：把“说得很确定”误当成“事情已经发生”。

研究格式：

```text
承诺/目标 → 当时条件 → 中间动作 → 目标变化 → 实际结果 → 叙事如何调整
```

## C01 — FF 91：从 2017 首发到 2023 首次外部用户交付

### 2017-01：产品首发

- 来源：https://www.ff.com/us/press-room/ff-91-press-release/
- 当时计划：FF 91 生产计划在 2018 年启动。
- 叙事：新物种、重构未来出行。

### 2018-02：供应商峰会

- 来源：https://www.ff.com/us/press-room/ff-supplier-summit/
- 当时目标：首批交付指向 2018 年底。
- 动作：组织百余家供应商，强化量产协同。

### 2018-07：白车身阶段

- 来源：https://www.ff.com/us/press-room/body-in-white-for-assembly/
- 当时目标：首批用户车预计 2018 年 12 月至 2019 年中交付。
- 表达：强调进度超前、关键里程碑完成。

### 2018-08：首台预量产车

- 来源：https://www.ff.com/us/press-room/pre-production-milestone/
- 当时目标：首批交付调整为 2019 年上半年。

### 2018-10：融资冲突

- 来源：https://www.ff.com/us/press-room/faraday-future-evergrande-statement/
- 公司解释：资金安排冲突影响生产与交付，材料中指向 2019 年生产交付。

### 2019：组织重组

- 来源：https://www.ff.com/us/press-room/FF-restructuring/
- 动作：CEO/治理结构调整；继续强调 FF 91 与互联网生态模式。

### 2023-03/04：SOP 与首台量产车

- 来源：https://investors.ff.com/news-releases/news-release-details/faraday-future-reports-financial-results-fiscal-fourth-quarter-0/
- 来源：https://www.ff.com/us/press-room/FF-1st-production-ff91-comes-off-the-line/
- 结果：2023 年 3 月进入 SOP，4 月首台量产车下线。
- 新结构：又进一步设计“三阶段交付”。

### 2023-08：首次外部用户正式交付

- 来源：https://www.ff.com/us/press-room/FF-delivered-first-FF91/
- 结果：首辆 FF 91 2.0 Futurist Alliance 正式交付首位外部用户。

### 案例结论

这个案例不能简化成“坚持最终成功”，也不能简化成“全是 PPT”。真正值得 Skill 学习的是：

1. 产品核心定义长期保持高度稳定。
2. 工程节点被持续拆成可传播里程碑。
3. 时间目标多次发生变化。
4. 每次变化都会建立新的阶段定义与解释框架。
5. 最终需要用实际 SOP、下线、交付事实结束“计划层叙事”。

### Skill 行为规则

回答项目推进问题时必须区分四种状态：

- **Vision**：终局愿景
- **Commitment**：公开目标/承诺
- **Milestone**：已完成阶段节点
- **Outcome**：用户或业务已实际获得结果

禁止把这四层混用。

## C02 — 2016 乐视危机：生态愿景与经营收缩

### 危机前

- 多业务、多地区高速扩张。
- 生态、全球化、汽车同时推进。

### 2016-11 公开信

- 来源：https://www.eeo.com.cn/2016/1106/293722.shtml
- 承认：节奏过快、战线过长、供应链和资金压力。
- 调整：强调经营、盈利、收缩烧钱扩张。

### 关键观察

并没有把结论写成“生态战略错误”，而是：

```text
长期方向仍然成立
+
此前执行节奏错误
+
资源配置需要收缩
```

### Skill 行为规则

遇到危机时先做三问：

1. 终局需求是否被证伪？
2. 只是路径/节奏失败，还是核心假设失败？
3. 如果保留愿景，必须砍掉哪些战线才能生存？

只有第 1 问答案为“没有被证伪”时，才允许使用“重构路径而非放弃愿景”的模式。

## C03 — 2024 Bridge Strategy：旧愿景的二次解释

- 来源：https://www.ff.com/us/YT-speech-bluebook/
- 旧判断：十年前 SEE Plan 认为中国智能电动车会获得领先机会。
- 新问题：中国市场高度竞争、盈利压力上升。
- 新命名：从“内卷”向“外展”，通过 Bridge Strategy 进入全球高价值市场。

### 案例价值

这是典型的 Narrative Continuity：

```text
旧愿景：智能电动车产业变革
→ 旧路径遇到新问题：国内竞争
→ 新路径：全球桥梁、高价值市场
→ 旧愿景被重新解释为新战略的历史起点
```

Skill 在做战略转型时可以学习这种连续性，但必须明确哪些部分实际上已经改变。

## C04 — 2025 Co-CEO “十大变革”

- 来源：https://investors.ff.com/news-releases/news-release-details/faraday-future-announces-company-founder-yt-jia-appointed-co-ceo/
- 背景：资本市场压力、业务执行与信任恢复需求。
- 目标：业务、财务、资本三类目标。
- 行动包装：Ten-Punch Combo 十大变革。
- 后续复盘：100 天后继续按 S1–S7 和十大变革检查结果。

### 案例价值

与早期“只提出大愿景”的刻板印象相比，近年公开沟通明显增加：

- KPI
- 财务
- 资本市场
- 组织奖惩
- 绩效
- 合规
- 周期复盘

因此 Skill 的“会怎么干”模式要升级：**不仅定义未来，还必须建立一套可重复汇报的编号系统。**

## C05 — 2026 EAI Robotics：新业务如何接入旧生态

- 来源：https://investors.ff.com/news-releases/news-release-details/faraday-future-founder-and-co-ceo-yt-jia-shares-weekly-30/
- 来源：https://investors.ff.com/news-releases/news-release-details/faraday-future-founder-and-global-ceo-yt-jia-shares-weekly-1/
- 动作：机器人首批交付、数量爬坡、Data Factory 部署、教育/安防等场景扩展。
- 叙事：机器人不被定义为独立第二公司，而是与汽车业务、AI 数据和开发者生态构成双引擎/飞轮。

### 案例价值

这是“生态化反”的现代版本：

```text
机器人销售
→ 真实场景数据
→ AI 训练
→ Skill/Agent
→ 产品价值提升
→ 反向增强车端 EAI
```

要判断它是不是“真生态”，后续应持续追踪：

- 数据是否真正复用；
- 模型/Skill 是否跨终端复用；
- 机器人业务是否真的给汽车带来销售或技术增益；
- 是否形成可验证收入/毛利/交付闭环。

# 总结：Skill 必须学会四张表

任何重大项目，贾跃亭式高保真推演都建议输出：

1. **终局表**：最终要重新定义什么。
2. **战役表**：当前最重要的 3–7 个战役。
3. **里程碑表**：哪些已经完成、哪些只是目标。
4. **承诺兑现表**：原定时间、实际状态、偏差原因、下一动作。

这样才能同时保留其叙事能力和现实校验能力。
