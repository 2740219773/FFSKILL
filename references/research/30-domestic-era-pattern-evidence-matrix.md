# Research 30 — 国内乐视时期稳定模式证据矩阵

更新时间：2026-09-03

目的：把 2011–2017 的旧资料从“故事”变成可审计的人物模式证据，避免后面核心 Skill 被近年 FF 材料重新覆盖。

## 证据等级

- **A**：本人公开信/完整演讲/完整采访直接支持。
- **B**：多家可靠媒体或员工观察交叉支持。
- **C**：研究推演，不能当本人事实。

# 一、强到足以进入核心 Skill 的历史母模型

## 1. Future-Back

2012：未来十年视频行业机会。

2013：传统电视将被智能电视替代，并给出 7 点未来预测。

2015：全球经济从专业化分工走向跨产业价值链重构。

2016：直接说出“用未来定义未来，再用未来定义现在”。

这条证据链比 FF 时期更加完整。

## 2. Reframe the Category

稳定动作：

```text
视频网站 → 生态公司
电视 → 家庭互联网计算中心/生态系统
手机 → 移动互联网生态系统
汽车 → 互联网智能终端/移动生活空间
```

不是“做更好的同类”，而是先改变类别定义。

## 3. Reframe the Unit of Competition

```text
产品 vs 产品
→ 产业链 vs 产业链
→ 生态系统 vs 生态系统
```

这是其思考商业问题时最有区分度的部分之一。

## 4. Mission + Execution

早期梦想叙事并非纯情绪：

```text
未来趋势
+ 历史使命
+ 团队
+ 创新
+ 执行
```

因此“为梦想窒息”如果脱离执行层，反而是低保真。

## 5. Founder-Led Strategic Inflection

2016 年面对“是不是自己说了算”的提问，本人明确区分：

- 上市体系按规范；
- 非上市体系在极个别重大拐点上由他决定；
- 理由是颠覆性方向往往不是多数人共识。

这是一个比“Founder-Led Product”更强的模型：

> 创始人不仅抓产品灵魂，也倾向在非共识重大拐点保留最终战略决断权。

### 风险

非共识 ≠ 正确。

因此 Skill 必须附：

- 证伪机制；
- 风险预算；
- 董事会/治理边界；
- 独立技术/财务校验。

## 6. Business-Model Subsidized Hardware

演化连续：

```text
2013 低毛利/接近成本
→ 2015 成本定价
→ 2015H2 负利定价
→ 2016 硬件免费
```

所以“硬件免费”本质是盈利单位迁移逻辑逐渐极化。

## 7. Crisis Reframing

2016H2 后：

```text
承认节奏/能力/资金问题
→ 不轻易放弃长期终局
→ 把收缩定义成第二阶段
→ 改组织和融资结构
```

这是后来 FF 多次危机表达的历史源头。

# 二、需要降权的误读

## 误读 1：贾跃亭一直是高情绪演说家

不准确。

2013 发布会和早期采访相对克制，2015–2016 才明显进入高情绪、高对立、高使命传播峰值。

## 误读 2：生态就是多元化扩张

不准确。

本人长期理论核心是：

```text
强相关产业要素
→ 垂直整合
→ 跨边界化学反应
→ 新用户价值
```

但现实中确实存在“强相关”边界被不断扩大的风险。

## 误读 3：所有决策都独断

证据不支持如此绝对。

本人明确区分上市体系规范治理与非上市体系重大拐点。

更准确的模型是：

> 在他认定属于“颠覆性重大拐点”的非共识问题上，创始人决断权权重极高。

## 误读 4：被质疑就是他判断正确

不成立。

“99%不看好才可能颠覆”是人物叙事和决策偏好，不是逻辑证明。

Skill 必须把它转换为：

> 如果选择非共识路径，需要更低成本、更快速、更客观的验证机制。

# 三、历史 Skill 权重建议

当用户明确要求 2015–2016 国内巅峰风格：

### 高权重

- Future-Back
- 指定旧范式
- 重定义竞争单位
- 第三范式创造
- 生态/破界
- 高确定性趋势判断
- 产品作为新范式证据
- 商业模式重构
- 质疑重构
- 使命式结尾

### 中权重

- 数字化结构
- 创始人个人经历
- 疯狂/少数人叙事
- 全球化
- 强对手对比

### 低权重/条件触发

- 悲壮哭诉
- 战争隐喻
- “All In”
- 危机反思

后面几项在 2016H2–2017 权重才明显上升。

# 结论

国内乐视时期不是现代 FF 风格的“旧版 UI”，而是整个模型的母代码：

```text
未来倒推
+ 类别重定义
+ 生态竞争单位
+ 非共识创始人决断
+ 商业模式补贴硬件
+ 高使命组织动员
+ 危机后叙事重构
```

现代 FF 的 S1–S7、Bridge、EAI、Weekly Report，更像是在这套母代码上增加了资本市场合规、里程碑管理和结果化经营。
