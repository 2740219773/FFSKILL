# Research 25 — 乐视年度战略主题演化：2011–2016

更新时间：2026-09-03

## 为什么这条线重要

2015 年 3 月的乐视年度战略沟通会上，贾跃亭本人回顾了此前连续五年的战略主题：

- 2011：生态战略正式起航
- 2012：激情成就梦想，梦想创造历史
- 2013：大屏生态颠覆产业格局
- 2014：生态决胜未来，协同产生聚变
- 2015：打造首个手机生态，全球合伙人召唤你

这条连续主题链说明，“生态 / 梦想 / 颠覆 / 协同 / 手机”并不是后来媒体总结出来的几个孤立标签，而是乐视内部连续多年主动构建的一条战略叙事。

## 1. 2011：生态战略正式起航

证据等级：B（由 2015 年本人回顾确认，仍待找到 2011 年原始演讲/邮件）

核心动作：

```text
从“视频网站”
→ 提出“生态系统”
→ 把公司身份从单业务公司拉高到系统型公司
```

重要性：

这是后面十多年所有“重新定义公司是什么”的母动作。

研究待办：

- 找是否已经使用“平台+内容+终端+应用”；
- 确认“生态系统”在当年是否已有完整定义。

## 2. 2012：激情成就梦想，梦想创造历史

A 类直接证据：2012-04-26 全员邮件。

典型结构：

```text
未来十年行业机会
→ 数千亿市场
→ 有机会创造历史
→ 伟大梦想
→ 团队 + 创新 + 执行力
→ 坚韧执着、永不言败
```

### 关键发现

早期“梦想”不是孤立的情绪口号，而是和三件事紧密绑定：

1. 对未来趋势的高确定性判断；
2. 团队与创新；
3. 执行力。

因此 Skill 模拟这一时期时，不应写成纯励志演讲。

更准确的骨架是：

```text
巨大未来机会
+ 我们有历史位置
+ 高强度组织执行
= 梦想创造历史
```

## 3. 2013：大屏生态颠覆产业格局

A/B 证据：2013-05-02 全员邮件、2013-05-07 超级电视发布、乐视官方历史发布会页。

主要来源：
- https://tech.sina.com.cn/i/2013-05-02/13388298361.shtml
- https://ent.le.com/zt/letv409/index.shtml
- https://special.cheaa.com/TeYue/20130507letv/

### 战略升级

2012 是“我们能不能创造历史”；2013 变成“具体颠覆谁、用什么产品证明”。

典型链：

```text
传统电视几十年没变化
→ 智能电视是未来
→ 电视不再只是电视
→ 家庭计算中心 / 家庭互联网生态系统
→ 内容 + 平台 + 应用 + 终端
→ 超级电视作为第一终端证明
```

### 重要方法

这一时期已经成熟出现：

- Future-Back；
- 指定旧范式；
- 产品重新定义；
- 垂直整合；
- “硬件不是终点，而是生态入口”；
- 低硬件利润换用户规模。

这说明 2015 超级手机的基本思路并非突然出现。

## 4. 2014：生态决胜未来，协同产生聚变

A 类直接证据：2014 年全员邮件“生态协同关乎乐视生死”。

主要来源：
- https://tech.cnr.cn/techhlw/201401/t20140122_514718944.shtml
- https://finance.sina.com.cn/leadership/mroll/20140127/093218095483.shtml
- https://www.huxiu.com/article/26874.html

### 这一步非常关键

生态从“外部产品战略”升级为“内部组织机制”。

逻辑是：

```text
生态链越来越长
→ 单业务成功不再够
→ 部门/业务之间必须协同
→ 协同产生聚变
→ 协同失败则内耗/生态坍塌
```

这里已经非常早地暴露出乐视模式的核心内在张力：

```text
生态越大
→ 理论协同收益越高
→ 同时组织复杂度也越高
```

因此“生态协同关乎生死”既是战略自信，也是对系统复杂性的早期自我警告。

## 5. 2015：打造首个手机生态，全球合伙人召唤你

A 类直接证据：2015-03-10 战略沟通会完整演讲。

### 新升级 1：从大屏迁移到移动终端

不是只做一台手机，而是把电视已经试过的模式迁移到手机：

```text
平台
+ 内容
+ 应用
+ 终端
+ EUI
→ 手机生态
```

### 新升级 2：从产品扩展到组织

“全球合伙人”把战略扩张和人才/股权机制绑在一起。

这说明人物做事方式不是：

> 先有产品，再补组织。

而更像：

```text
战略终局
→ 新业务
→ 新组织能力
→ 新人才机制
```

### 新升级 3：使命进一步放大

演讲开头不从手机参数开始，而从环境、未来社会、使命和梦想开始。

典型顺序：

```text
社会问题
→ 历史使命
→ 团队角色
→ 新战略
→ 手机生态
```

## 6. 2015 H2：从“生态化反”进一步转向指数化、人格化

10 月 27 日乐1s发布会把数字“2”做成整场叙事主轴：

- 2 = 傻子/疯子精神；
- 2 = 平方，指数级生态化反；
- 2 = 独一无二。

这说明 **Naming Creates Strategy** 不只会创造行业名词，也会把一个普通符号重新定义成人格、战略和传播共同载体。

## 7. 2016 H1：无破界不生态 / 硬件免费

来源：
- https://tech.sina.com.cn/2016-04-10/doc-ifxrcizs7159766.shtml

演化：

```text
生态
→ 生态化反
→ 破界
→ 硬件免费
→ ET 时代 / 生态消费观
```

此时已经达到国内时期叙事强度峰值：

- 旧势力 / 旧商业模式被人格化；
- “硬件价格”被重新定义为旧时代规则；
- 四类跨产业终端被描述成共享同一大脑/神经/血脉；
- “用未来定义未来，再用未来定义现在”明确写出 Future-Back；
- 最终进入“改变历史 / 也许会死在成功路上”的使命收尾。

## 8. 2016 H2：从扩张叙事转向危机重构

11 月公开信承认：

- 节奏过快；
- 全球战线过长；
- 资金和资源无法支撑规模；
- 汽车投入巨大；
- 融资结构和能力不足。

来源：
- https://companies.caixin.com/2016-11-06/101004558.html

但核心叙事不是“生态战略错误”，而是：

```text
第一阶段扩张过快
→ 进入第二阶段
→ 从蒙眼狂奔转向聚焦
→ 保留生态终局
```

这就是后来长期 Crisis Reframing 的历史母型。

# 一条更准确的战略演化公式

```text
2011 重新定义公司
→ 2012 给公司注入梦想/历史使命
→ 2013 用超级电视证明生态产品化
→ 2014 把生态变成组织协同机制
→ 2015 把生态迁移到手机并全球化
→ 2015H2 把概念人格化/指数化
→ 2016H1 把生态升级为产业破界和商业模式革命
→ 2016H2 在资源危机中重构节奏而保留终局
```

# 对 Skill 的直接影响

## 早期“贾跃亭式”不能省略的底层顺序

```text
未来趋势
→ 历史使命
→ 旧范式
→ 新系统
→ 产品入口
→ 商业模式
→ 组织/伙伴
→ 用户价值
→ 梦想/历史
```

## 早期高频词只是表层

`梦想 / 颠覆 / 生态 / 化反 / 破界 / 超级`

真正稳定的是它们背后的功能：

- 梦想 = 长期使命绑定执行；
- 颠覆 = 明确旧规则并提出新规则；
- 生态 = 重新定义竞争单位；
- 化反 = 模块双向强化；
- 破界 = 打掉原产业边界；
- 超级 = “硬件 + 服务 + 生态”的新类别命名。

只复制词汇，不复制这些功能，属于低保真。
