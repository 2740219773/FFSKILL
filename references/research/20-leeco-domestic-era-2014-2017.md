# Research 20 — 国内乐视时期核心一手/近一手资料（2014–2017）

更新时间：2026-09-03

目的：把 FFSKILL 的人物源头从近年 FF 周报重新向前追溯。2014–2017 是贾跃亭公开表达、产品哲学和组织风格最集中成型的阶段，尤其是超级电视、超级手机、SEE 汽车、生态化反、硬件免费、为梦想窒息、蒙眼狂奔以及资金危机前后的材料。

> 原则：本文件只做摘要和研究提炼，不复制长篇原文。本人演讲/公开信/完整访谈优先；记者观察、前员工回忆单独降级处理。

## 1. 2014-01 — “生态协同关乎生死”内部信

来源：新浪财经转载乐视 CEO 贾跃亭致全体员工信  
链接：https://finance.sina.com.cn/leadership/mroll/20140127/093218095483.shtml

### 核心内容

- 明确提出“生态整合将战胜专业化分工”。
- 把乐视从视频公司向“平台+内容+终端+应用”的生态型公司转型。
- 用“用户、前瞻、快速、协同、极致”总结互联网模式的关键能力。
- 把跨部门协同定义为组织层面的生死线。
- 2014 年主题从上一年的“激情与梦想”转到“协同年”。
- 已经出现“战略 → 组织 → 协同 → 聚变”的完整管理逻辑。

### 研究价值

这说明“生态”并不是 2015 手机发布会临时创造出来的营销词，而是至少在 2014 年已经进入战略、组织和管理层。

证据等级：A2（公开员工信）

## 2. 2014-12 — SEE 计划公开：用生态逻辑重新定义汽车

来源：新浪汽车对其微博/内部邮件的报道  
链接：https://auto.sina.com.cn/news/2014-12-09/11051367219.shtml

### 核心内容

- 汽车被放入“移动互联网时代的产业革命”而非单纯造车语境。
- SEE 计划试图复制乐视的垂直整合模式到汽车。
- 汽车被定义为生态的新入口和新的互联网生活场景。
- 一开始就使用“重新定义汽车”“弯道颠覆传统巨头”等高确定性叙事。

### 研究价值

这是 Future-Back、Boundary Breaking 和“新终端作为生态入口”迁移到汽车领域的早期证据。

证据等级：A/B（微博直接表达 + 媒体转述）

## 3. 2015-03 — 手机战略沟通会：手机不是新业务，而是生态决胜战

来源：新浪科技，含贾跃亭演讲全文  
链接：https://tech.sina.com.cn/t/2015-03-10/doc-ichmifpx9921291.shtml

### 核心内容

- 把 2011–2015 每年主题串成连续战略演化。
- 2015 年目标明确转向“打造首个手机生态”。
- 将手机称为当年最重要的核心战略之一。
- 使命、梦想、环境问题、SEE 汽车与手机生态被统一进一套大叙事。

### 研究价值

这里已经形成后来非常稳定的“过去战略连续性 → 当前关键战役 → 更大终局”的结构。

证据等级：A1/A2

## 4. 2015-04-12 — 《致苹果的一封信》：先制造旧范式敌人，再定义新范式

来源：新浪科技  
链接：https://tech.sina.com.cn/t/2015-04-12/doc-iawzuney3125437.shtml

### 核心内容

- 把苹果定义为封闭旧范式代表。
- 用“开放的闭环”构造乐视自己的对立面。
- 强调超级手机不是单一手机，而是完整移动互联网生态系统。
- 手机、电视、汽车被解释为同一生态能力向不同终端迁移。
- 典型句法：旧范式问题 → 新范式定义 → 用户痛点 → 生态价值 → 宣言式收尾。

### 研究价值

这是“不是 A，而是 B”“旧巨头=旧规则”“我们不是做产品，而是在重定义关系”的标准样本。

证据等级：A1

## 5. 2015-04-14 — 第一代超级手机发布会

来源：人民日报《环球人物》长访谈及中国日报现场报道  
链接：
- https://paper.people.com.cn/hqrw/html/2015-05/06/content_1631010.htm
- https://cnews.chinadaily.com.cn/2015-04/14/content_20433893.htm

### 核心内容

- 中美同步、长时间独立演讲，大量使用产业史/苹果对照做产品发布铺垫。

## 6. 2015-05-17 — 致乐迷家书：“为梦想窒息”进入标志性表达

来源：新浪科技  
链接：https://tech.sina.com.cn/i/2015-05-17/doc-iawzuney5713363.shtml

### 核心内容

- 超级电视、超级手机、超级汽车被串成一条生态进化线。
- 把手机预约/用户规模上升解释为生态模式的证明。
- 大量使用“坚信、超越、未来、风雨兼程”等高信念词汇。
- 文末出现“为梦想窒息”，成为之后传播最广的标志性表达之一。

### 研究价值

“为梦想窒息”不是孤立口号，它嵌在完整结构中：

```text
质疑/竞争
→ 产品与用户进展
→ 生态模式意义
→ 长期未来
→ 苦难/选择
→ 梦想宣言
```

因此 Skill 不应该把它当作每段都能插入的口癖。

证据等级：A1

## 7. 2015-05 — 《我是拿长矛的堂吉诃德》长访谈

来源：《环球人物》  
链接：https://paper.people.com.cn/hqrw/html/2015-05/06/content_1631010.htm

### 核心内容

本人部分：

- 生态不是乐视自己的选择，而被解释为时代选择。
- 对“贪多嚼不烂”的质疑，回答方式不是收缩，而是重新定义产业规律。
- 明确认为少而精/专业分工属于工业时代，垂直整合更适合互联网时代。
- 承认资金一直是短板，但相信生态自身现金流与未来融资会解决。
- 对质疑强调“99% 不看好”反而意味着真正颠覆。

记者/员工观察部分：

- 长时间、高强度工作。
- 对产品和网页细节介入很深。
- 员工感受到明显压力与距离感。
- 学习速度快、会迅速补齐陌生领域知识。

### 研究价值

这是同时研究“怎么想、怎么说、怎么管”的核心材料。

注意：工作时长、微观细节等属于记者/员工观察，不能当成本人自述。

证据等级：A1 + B1

## 8. 2015-08 — “乐视模式并非不专注”

来源：新浪财经  
链接：https://finance.sina.com.cn/chanjing/gsnews/20150804/110922871842.shtml

### 核心内容

- 面对“不专注”质疑，贾跃亭不是接受传统专注定义，而是重新定义“专注对象”。
- 他的专注单位不是单一产品，而是整个生态系统。
- 手机、汽车等行业被放进 5–20 年产业周期和下一代范式中讨论。

### 研究价值

这是“重新定义问题边界”最典型的防守性叙事之一：

```text
别人问：为什么不专注单点？
回答：你把专注的单位定义错了；我们专注的是整个生态。
```

这条逻辑后来在 FF 的双飞轮/双桥争议中再次出现。

证据等级：A/B

## 10. 2016-04-10 — 公开信：硬件免费 + 无破界不生态

来源：新浪科技  
链接：https://tech.sina.com.cn/2016-04-10/doc-ifxrcizs7159766.shtml

### 核心内容

- 把硬件利润、品牌溢价、渠道溢价定义成旧消费关系。
- 用“硬件免费”创造新的商业关系命题。
- 同期多个产品发布被统一组织为生态事件链。
- 明确使用“无疯狂，不生态”“无破界，不生态”等强传播性命名。
- 出现“用未来定义未来，再用未来定义现在”的典型 Future-Back 表达。
- 即使承认可能失败，也保持极高行动确定性。

### 研究价值

这是早期贾跃亭表达 DNA 密度最高的一篇材料之一，可作为 2014–2016 路由的核心母语料。

证据等级：A1

## 13. 2016-11 — 《海水与火焰》：国内阶段最关键的自我纠偏

来源：经济观察网（转载全员信）  
链接：https://www.eeo.com.cn/2016/1106/293722.shtml

### 核心内容

- 第一次系统承认战略节奏过快、战线拉得太长、资金和组织能力跟不上。
- 将过去阶段重新命名为生态战略第一阶段。

证据等级：A1

# 国内时期最值得提炼的 10 个稳定特征

1. **先定义时代，再定义产品。**
2. **通过制造旧范式对手来凸显新范式。**
3. **把单品竞争升级成系统/生态竞争。**
4. **新业务必须被解释为旧生态能力的迁移或新入口。**
5. **极高确定性：战略判断往往远高于当时已有证据。**
6. **喜欢把质疑本身转化成“创新者被误解”的证明。**
7. **战略命名能力极强：生态、超级、破界、化反、硬件免费、SEE。**
8. **使命/梦想并不是装饰，而是组织动员工具。**
9. **创始人对产品、战略和部分细节介入很深。**
10. **危机后更倾向“方向保留、节奏/组织重构”，而非完全推翻旧终局。**

# 对 FFSKILL 的直接影响

2014–2016 路由不应只是“把现代回答换成梦想/生态词汇”。它应该使用完全不同的生成顺序：

```text
时代正在变什么
→ 工业/传统范式为什么失效
→ 指定一个旧范式代表
→ 提出新的产业关系
→ 用一个高传播概念命名
→ 把产品放进整个生态
→ 强调用户价值和长期使命
→ 高信念宣言
```

而 2016 H2–2017 应进入：

```text
承认扩张/组织/现金问题
→ 仍然坚持生态终局
→ 把错误归类到节奏/执行/组织
→ 收缩战线
→ 重构管理机制
→ 定义第二阶段
```

这两套结构都应与 2025–2026 Weekly Report 路由分开。
