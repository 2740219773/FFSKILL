# Research 27 — 2015-04-14 超级手机发布会结构解剖

更新时间：2026-09-03

研究对象：2015 年 4 月 14 日乐视超级手机发布会。这是“为梦想窒息时代”最重要的公开表达样本之一。

## 1. 为什么这是国内时期最关键的一场

贾跃亭独自演讲约两个小时，而且不是从手机参数开始。

整场发布会先构造一个“旧世界即将结束”的宏大叙事，再把超级手机作为新范式的实物入口。

这是其公开表达从“产品战略”进入“产业战争 + 创始人使命”阶段的成熟形态。

---

## 2. 开场：先制造一个符号化敌人

开场使用苹果《1984》广告的改编意象，把苹果从当年的革命者重新定义成今天的“旧秩序代表”。

叙事操作：

```text
先承认对手过去的伟大
→ 指出对手成功模式在新时代变成限制
→ 把自己放在新革命者位置
```

这比简单说“苹果不好”更有效，因为它不是产品对比，而是历史角色反转。

### 可抽象为 Skill 模板

```text
A 曾经解决旧时代问题
→ 但 A 的成功机制如今开始制造新问题
→ 新时代需要 B
```

---

## 3. 第一大核心：不是做一台手机，而是重定义手机

贾跃亭把手机竞争分成不同阶段，并把乐视定位为“生态手机”。

典型逻辑：

```text
功能机
→ 智能机
→ 生态手机
```

这种“代际划分”是其典型方法：先把行业重新分期，然后把自己的产品放在下一代。

### Skill 规则

只有真的存在结构性变化时才能使用“X.0/新时代”。

不能为了人物感把任何小升级都写成新代际。

---

## 4. 第二大核心：开放闭环

他没有简单站在“开放 vs 封闭”其中一边，而是创造“开放的闭环”作为第三种模式。

结构：

```text
苹果：闭环但封闭
安卓：开放但碎片化
乐视：开放 + 闭环
```

这是一个很典型的“拒绝二选一 → 创造第三范式”动作。

### 稳定思维模型

```text
找到两种主流方案各自的结构缺陷
→ 不选边
→ 组合成第三种新范式
```

这比“不是 A，而是 B”还多一层：

```text
不是 A
也不是 B
而是重新定义 C
```

---

## 5. 第三大核心：产品只是完整生态的入口

公开材料里反复强调：

```text
超级手机 ≠ 单一硬件
超级手机 = 移动互联网生态系统入口
```

核心要素：

- EUI；
- 内容；
- 应用；
- 服务；
- 会员；
- 硬件；
- 云平台。

因此产品介绍会不断从一个具体功能跳回整个生态体系。

---

## 6. 第四大核心：生态化反

“化反”不是单纯协同，而强调一端变化会反过来要求另一端变化。

典型链：

```text
内容/服务创新
→ 需要更强终端能力
→ 硬件升级
→ 新硬件反过来允许新内容/服务体验
```

这就是后来 Skill 中“双向增益”定义的历史证据。

---

## 7. 产品参数在整场中的位置

产品参数并非不重要，而是在宏观叙事之后成为“我们真的能做出来”的证据。

典型发布节奏：

```text
行业问题
→ 商业模式
→ EUI/生态
→ 手机本体
→ 参数/工艺/性能
→ 价格
→ 生态会员/服务
```

也就是说：

> 参数服务于战略叙事，而不是战略叙事服务于参数。

---

## 8. 价格不是单纯价格战

超级手机采用接近量产成本的定价逻辑，并将会员/内容服务纳入商业模型。

因此“低价”被重新解释为：

```text
不是为了硬件价格战
→ 而是因为盈利单位从单台硬件变成用户全生命周期
```

这条逻辑后来继续升级为“硬件负利”“硬件免费”。

---

## 9. 发布会中的对立结构

2015 的人物辨识度很大一部分来自强烈二元对照：

- 苹果旧模式 vs 乐视新模式；
- 封闭 vs 开放闭环；
- 工业时代 vs 互联网生态时代；
- 等风者 vs 造风者；
- 单点竞争 vs 生态竞争；
- 硬件价值 vs 用户长期价值。

### Skill 风险

这种结构非常有传播力，也容易制造虚假二分。

因此每次使用必须检查：

> A/B 是否真的互斥？是否遗漏第三种现实方案？

---

## 10. “质疑”如何被利用

发布会和后续采访里，外界不看好不被当作纯负面，而被纳入“颠覆者必然被误解”的故事。

典型链：

```text
大多数人看不懂
→ 说明我们走的是新路
→ 历史上的颠覆者也曾被质疑
→ 用未来事实证明
```

### 必须增加的反证

“被多数人反对”本身不能证明方向正确。

所以 Skill 只允许把质疑作为：

> 新范式需要额外验证的信号。

不能把它当作正确性的证据。

---

## 11. 演讲情绪节奏

相比 2013，2015 的情绪强度显著升级。

```text
历史转折
→ 敌人符号化
→ 自我定位为颠覆者
→ 新模式解释
→ 技术/产品证据
→ 价格冲击
→ 全球化目标
→ 用户/梦想/使命
```

并且长演讲中会不断循环：

```text
宏观
→ 具体
→ 宏观
→ 具体
```

这使两小时内容不会退化成连续参数表。

# 2015 超级手机发布会生成模板

```text
1. 先说时代已经改变了什么。
2. 选择一个代表旧规则的强势对象。
3. 承认其曾经伟大，再解释其成功机制为何开始失效。
4. 不在现有 A/B 两条路中选边，提出第三范式。
5. 给第三范式一个高传播名称。
6. 解释平台、内容、应用、终端之间如何双向增强。
7. 再拿具体产品、功能、参数证明不是 PPT。
8. 用新商业模式解释价格为何可以改变。
9. 把产品重新连接回用户长期价值。
10. 回应“不可能/疯狂”的质疑。
11. 用未来、使命、梦想做开放式收尾。
```

# 一句话结论

2015 年的“贾跃亭式发布会”最核心的不是喊“生态”，而是：

> **先重新定义竞争规则，再把产品作为新规则的第一件证据。**
