# Research 37 — 2012–2014 母代码形成史：从产品重定义到组织重构

更新时间：2026-09-03

目的：把“超级手机/为梦想窒息”之前三年的当期资料连成一条直接证据链，回答一个核心问题：2015 年的表达和决策方式究竟是突然形成，还是此前已有稳定母代码？

结论：**至少从 2012–2014 的当期资料看，2015 手机时期的核心母逻辑已经逐步形成：先定义旧范式失效，再重新定义产品类别，再建立跨产业链闭环，最后让组织结构追随生态战略。**

---

# 1. 2012-09-19：先宣布新类别，再补产品

“颠覆日”当日报道明确记录：

- 乐视宣布进入智能电视；
- “超级电视”被定义为未来电视方向，而不是普通智能电视；
- “平台 + 内容 + 终端 + 应用”构成完整生态系统；
- 商业、盈利、营销模式被同时重新设计；
- 盈利来源不只硬件，还包括内容、应用分成、终端广告。

来源：
- 中国家电网：https://news.cheaa.com/2012/0920/338244.shtml
- 乐视历史专题：https://ent.le.com/zt/letv409/index.shtml

## 结构

```text
传统电视
→ 不是功能升级问题
→ 产品类别应该改变
→ 互联网平台/内容/终端/应用必须合一
→ 盈利单位改变
→ 超级电视成为新系统入口
```

这已经非常接近后来超级手机的“产品不是产品，而是生态入口”。

## 重要反证

2012 发布会阶段并没有完成最终实物产品证明。

因此必须区分：

```text
2012：Vision / Commitment
2013：Product / Market Milestone
```

这也是早期人物模型里“概念可以领先产品”的真实历史样本。

# 2. 2013-05：新旧范式对照成熟

2013 年超级电视发布前内部邮件中，贾跃亭已经使用非常完整的新旧范式表达：

- 传统电视被描述为单硬件时代；
- 超级电视被定义成家庭互联网生态系统；
- “他们/我们”形成清晰对照；
- 强调用户参与产品创造；
- 不靠单次硬件高毛利，服务从硬件售出后才真正开始。

来源：
- 新浪科技：https://tech.sina.com.cn/i/2013-05-02/13388298361.shtml

## 母结构

```text
旧类别已经死亡
→ 未来趋势清单
→ 旧产业代表
→ 旧系统结构性缺陷
→ 新系统完整定义
→ 用户共同创造
→ 产品/价格/供应链证明
```

这说明 2015“苹果旧范式 vs 乐视新范式”并非第一次使用敌我范式，而是电视时期已成熟。

# 3. 2013：商业模式的关键不是低价，而是利润单位改变

当年公开采访中，贾跃亭明确区分乐视与传统硬件公司的盈利结构：

```text
传统模式：硬件一次性利润
乐视模式：硬件 + 内容 + 广告 + 应用分成 + 后续服务
```

来源：
- 中国日报：https://www.chinadaily.com.cn/tech/2013-05/27/content_16534794_4.htm
- 新浪科技：https://tech.sina.com.cn/i/2013-09-05/09188710018.shtml

这说明“成本定价/硬件免费”的真正母逻辑不是便宜，而是：

> **把利润核算单位从单台硬件迁移到用户生命周期和生态服务。**

Skill 因此不能机械学习“低价/免费”，而要学习“重新定义利润单位”。

# 4. 2014：跨界从产品方法升级成组织方法

2014 年公开报道显示，随着平台+内容+终端+应用落地，乐视开始把跨界协同写进组织结构：

- 星期天跨业务会议；
- 扁平/网格化；
- 管理型组织 + 项目型组织；
- 跨层级资源调度；
- 生态决策委员会；
- 生态型考核和激励。

来源：
- 新浪科技：https://tech.sina.com.cn/i/2014-01-27/11589131647.shtml
- 人民网：https://finance.people.com.cn/n/2014/0605/c1004-25108860.html

## 结构升级

```text
2012–2013：产品系统必须跨界
→
2014：组织本身也必须跨界
```

这是一个非常关键的长期模型：

> **战略不是要求既有组织“更努力”，而是要求组织结构本身发生变化。**

# 5. 2014 H2：又出现“去 CEO 中心化”的组织成熟方向

2014 全球化内部邮件明确提出：

- 团队不是一个人的战斗；
- 业务决策从 CEO 主导向核心团队主动创新、集体决策转型；
- 管理型/项目型组织并行；
- 目标是组织自我进化和快速决策。

来源：
- 中国经济网：https://www.ce.cn/cysc/tech/rw/201409/23/t20140923_3580963.shtml
- 每日经济新闻：https://www.nbd.com.cn/articles/2014-09-23/865050.html

这条证据很重要，因为它反驳了“乐视组织哲学就是全部围绕一个人”的过度简化。

# 7. 2012–2014 到 2015 的连续演化

可以压缩成：

```text
2012
重新定义产品类别
+ 完整生态结构
+ 多重盈利模式

↓

2013
新旧范式对照成熟
+ 产品成为生态入口
+ 用户生命周期利润

↓

2014
生态协同写入组织
+ 管理线/项目线并行
+ 核心团队集体决策方向

↓

2015
把同一逻辑复制到手机
+ 苹果成为旧范式符号
+ 开放闭环/生态化反命名
+ 梦想叙事达到传播峰值
```

因此：

> **超级手机时期不是人物逻辑的起点，而是此前三年产品、商业模式、组织理论的传播峰值。**

# 8. 对 Skill 的新增权重

## 高置信跨时期模型

### P1 — Category Redefinition

不满足于旧类别优化，先问类别本身是否过时。

### P2 — Profit-Unit Redefinition

不是简单降价，而是重新决定“在哪个时间/系统层级赚钱”。

### P3 — Strategy → Organization

当战略依赖跨界协同时，组织边界必须同步改变。

### P4 — Distributed Execution / Centralized Inflection

执行协同可分布，重大不可逆战略拐点可能集中。

### P5 — Concept Before Full Proof

其历史上常出现：先把未来类别说完整，再用后续产品/里程碑逐步证明。

这既是传播优势，也是承诺风险来源。

---

# 9. 必须保留的失败边界

上述能力不能独立使用：

- Category Redefinition → 检查用户是否真的需要新类别；
- Profit-Unit Redefinition → 检查现金转换周期；
- Strategy → Organization → 检查组织吸收速度；
- Centralized Inflection → 检查是否真是不可逆拐点；
- Concept Before Proof → 明确 V/C/M/O，不能把概念当结果。
