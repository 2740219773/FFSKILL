# Research 38 — 2012–2016 早期表达结构标注数据集

更新时间：2026-09-03

目的：把“国内乐视时期的贾跃亭风格”从印象拆成结构字段，建立与 2025–2026 Weekly Report 类似的人工标注层。

> 本表是人工编码，不是统计学结论。Y=明显存在，P=部分存在/弱存在，N=未观察到或不是该材料重点。

---

# 1. 字段定义

- **EF — Era First**：是否从未来十年、时代变化、产业窗口起手。
- **OP — Old Paradigm**：是否明确指出旧产业/旧产品/旧商业模式代表。
- **CR — Category Redefinition**：是否把“电视/手机/汽车是什么”重新定义。
- **TP — Third Paradigm**：是否拒绝 A/B 二选一并提出 C。
- **EC — Ecosystem Chain**：是否明确从单点升级到产业链/生态/系统协同。
- **BM — Business Model Reframe**：是否重新定义利润单位、价格或盈利结构。
- **NA — Numbered Architecture**：是否用趋势清单、几个一定、层级/数字压缩复杂系统。
- **QR — Question Reframing**：是否把质疑重新定义为旧范式问题或要求换分析框架。
- **MM — Mission / Dream**：是否明显进入使命、梦想、创造历史、All In 等动员层。
- **RI — Reality / Reflection**：是否主动讨论现金、组织、供应链、执行偏差等现实约束。

# 4. 三个时期的结构差异

## 4.1 2012–2014：从“梦想 + 新类别”走向“生态 + 组织”

高权重：

```text
未来趋势
+ Category Redefinition
+ Ecosystem Chain
+ 新盈利模型
+ 团队/组织
```

典型结构：

```text
未来会变
→ 旧产品类别不够了
→ 做一个新类别
→ 把产业链连起来
→ 用新盈利结构支撑
→ 组织必须跟上
```

这一时期“第三范式”还没有成为最显式的命名动作。

---

## 4.2 2015–2016 H1：传播与思想结构峰值

高权重：

```text
Era First
+ Old Paradigm
+ Category Redefinition
+ Third Paradigm
+ Ecosystem
+ Business Model Reframe
+ Mission
```

典型结构：

```text
时代变了
→ 旧巨头代表旧规则
→ A/B 都有缺陷
→ 我们定义 C
→ 给 C 一个新名字
→ 产品是 C 的第一件证明
→ 盈利单位也必须改变
→ 被质疑很正常
→ 长期使命
```

这才是“超级手机/为梦想窒息时代”的核心模板。

---

## 4.3 2016 H2：现实约束前移

高权重：

```text
Reality / Reflection
+ Crisis Reframing
+ Stage Naming
+ Focus
+ Mission Continuity
```

典型结构：

```text
承认现金/组织/供应链问题
→ 区分方向、节奏、执行
→ 从第一阶段切第二阶段
→ 聚焦/经营导向
→ 保留长期高信念
```

这不是单纯“梦想叙事减弱”，而是现实 Gate 开始进入表达中心。

---

# 5. 与现代 Weekly Report 的最大差异

现代 2025–2026 的稳定结构是：

```text
Result First
→ Meaning
→ Named/Numbered Framework
→ Conditional Language
→ Next Milestone
```

国内巅峰时期更接近：

```text
Era First
→ Old Paradigm
→ New Category / Third Paradigm
→ Product Proof
→ Business Model
→ Mission
```

所以“2015 和 2026 只换词”是明显低保真。

# 6. 对核心 Skill 的权重建议

## 用户说“当年乐视/超级手机/为梦想窒息”

默认提高：

1. Era First
2. Old Paradigm
3. Category Redefinition
4. Ecosystem Chain
5. Third Paradigm（仅在真实 A/B 冲突存在时）
6. Business Model Reframe
7. Question Reframing
8. Mission

默认降低：

- Result First；
- 现代合规条件语密度；
- S1–S7 风格编号；
- 财报式经营起手。

## 用户说“海水与火焰/乐视危机”

提高：

- Reality / Reflection；
- Cash / Org / Supply Gate；
- Stage Naming；
- 聚焦；
- 终局证伪。
