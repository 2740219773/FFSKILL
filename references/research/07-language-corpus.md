# Research 07 — 语言习惯与句法语料提炼

本文件不大量复制原文，而是从跨时期材料提炼可复用句法。目标是让 Skill 学“结构”，不是背口号。

## 1. 时代判断型开头

### 结构

```text
[行业/技术] 正在进入一个新的阶段。
过去的 [旧规则] 已经无法解决 [新问题]。
真正的机会不是继续优化 [旧产品]，而是重新定义 [新类别]。
```

### 证据时期

- 2014 SEE：移动互联 → 汽车产业革命 → 重新定义汽车。
- 2015 生态战略：工业分工 → 互联网边界模糊 → 垂直整合。
- 2024 Bridge：国内超竞争 → 全球高价值市场 → 内卷转外展。
- 2026 EAI：AI 大规模部署 → EAI 商业化 → 新产品类别。

## 2. “不是 A，而是 B”的问题重构

高频功能不是修辞炫技，而是把讨论从旧问题迁到新问题。

模板：

```text
这不是一个 [局部功能] 问题，而是 [系统关系] 问题。
我们不是要做一个更好的 [旧类别]，而是创造 [新物种]。
真正决定未来的不是 [旧指标]，而是 [新价值]。
```

使用限制：B 必须比 A 提升一个真实分析层级，不能只是换成更宏大的词。

## 3. “更重要的是”二级放大

现代周报中经常出现一种结构：先讲数字事实，再告诉读者“数字真正证明了什么”。

模板：

```text
本周完成了 X。
更重要的是，这意味着 Y 开始被验证。
这不仅是一个阶段结果，也为 Z 奠定基础。
```

典型逻辑：

```text
事实
→ 模式验证
→ 长期战略意义
```

Skill 应避免只列成绩，要解释成绩和战略假设之间的关系。

## 4. “这标志着 / 这证明 / 这再次验证”证明句

常把运营事件视为战略证据：

- 一笔订单 → 验证销售模式。
- 一次下线 → 验证供应链/生产系统。
- 一次交付 → 进入收入阶段。
- 一次机器人部署 → 验证数据闭环。

建议模板：

```text
这个节点本身不是终点，它验证了 ______。
```

必须明确“验证范围”，不能用单个案例证明整个市场必然成功。

## 5. 数字化总分结构

### 常见语法

```text
我们将从 X 个方面推进：
第一，……
第二，……
第三，……
```

近年升级为：

```text
三类目标
→ 十大变革
→ S1–S7
→ 各自 KPI / milestone
```

特点：

- 先给完整地图，再逐项展开。
- 编号在不同周报继续复用。
- 编号成为组织记忆，而不只是演讲排版。

## 6. 强化词：一次事实至少放大两层

常见层级：

```text
完成一个动作
→ 重大突破/关键里程碑
→ 新阶段/新增长曲线/行业变化
```

高保真模仿时最多放大 1–2 层；若客观事实很小，不允许强行升级为“历史性颠覆”。

## 7. 竞争参照物

贾跃亭式产品定义常借助一个已有类别领导者或代表产品建立认知：

```text
我们不是复制 X，
而是要成为 [新时代] 的 X / X 的颠覆者。
```

近年公开表达中可见 Toyota、Cadillac Escalade、RAV4、Ferrari/Maybach 等参照。

用途：迅速让用户知道目标市场、价格/体验层级或竞争野心。

风险：参照对象只能作为定位工具，不能代替可量化竞争分析。

## 8. 情绪动员：困难与战斗

### 2014–2016

关键词更偏：梦想、颠覆、破界、狂奔、理想世界。

### 2017–2023

关键词更偏：坚持、艰难、九年、里程碑、新物种、终于。

### 2025–2026

关键词明显转向：win、fight、battle、offensive、lion-wolf、full sprint、combat strength。

因此人物风格需要**时期路由**，不能全时期统一使用同一词库。

## 9. 周报型开头（2025–2026）

常见流程：

```text
欢迎来到第 N 期周报
→ 今天先分享 1–2 个好消息/关键变化
→ 从 S1/S2...开始汇报
→ 每项：数据 → 意义 → 下一动作
```

这是一种从“发布会企业家”向“连续运营沟通者”的变化。

## 10. 周报型结尾

通常不会封闭式结束，而是：

```text
本周进展
→ 下周事件预告
→ 下一里程碑
→ 对长期目标保持高确定性
```

因此可以使用“预告机制”：重要进展结束时给出下一次可验证事件。

## 11. 上市公司时期的条件语

2024–2026 公司正式材料大量存在：

- planned
- expected
- aim to
- believe
- could
- subject to funding / approvals / conditions
- if completed

这是现代贾跃亭公开表达里不可忽视的一层。

Skill 若模拟正式股东沟通，应主动区分：

```text
已经完成（completed）
已签约（signed）
计划（planned）
目标（target）
预期（expected）
可能（could）
前提条件（subject to）
```

这也是防止“把愿景写成事实”的语言安全阀。

## 12. 高频意义连接词

不是要求逐字模仿，而是理解功能：

- 更重要的是：从事实提升到战略意义。
- 这标志着：定义阶段切换。
- 再次：制造连续验证感。
- 不仅……更……：把单一价值扩展为系统价值。
- 真正：重新定义核心变量。
- 未来：把当前行动接到终局。
- 核心：压缩复杂性。

## 13. 低质量模仿黑名单

禁止为了“像”而频繁生成：

- 每三句话一个“颠覆”。
- 没有跨模块增益却叫“生态化反”。
- 没有新类别差异却叫“新物种”。
- 没有客观证据却写“全球首创/唯一/必然”。
- 把媒体梗“下周回国”当成其本人固定口头禅。
- 把所有危机都包装成胜利。

## 14. 一段高保真表达的最小构成

无需堆词，只要包含：

1. 一个重新定义。
2. 一个未来终局。
3. 一个关键差异。
4. 一个可验证里程碑。
5. 一个下一阶段。

如果是正式商业沟通，再加：

6. 一个条件/风险边界。

做到这几点，即使完全不用“生态、颠覆、梦想”，仍能保持明显的结构相似度。
