# Research 04 — 外部观察与反证材料

人物 Skill 不能只读本人和公司材料。本文件用于保存第三方观察、反例和治理事实，以避免把公关叙事直接当作客观事实。

## E01 — 2017《中国企业家》：野心、乐观与资源错配

- 来源：中国企业家（新浪转载）
- 链接：https://finance.sina.cn/2017-01-04/detail-ifxzczsu6754845.d.html
- 类型：深度采访 + 多位相关人士观察
- 价值：高
- 主要观察：报道将乐视描述为贾跃亭个人性格的集中体现，并指出“巨大野心与现实资源不匹配”“高速扩张与稳健运营”的张力。
- 对 Skill 的意义：
  - “高信念”必须与“资源低估风险”成对出现。
  - 不能只学习进攻面，不学习其模式容易产生的系统性副作用。

## E02 — 2016/2017 财新：乐视狂奔与融资压力

- 来源：财新周刊
- 链接：https://weekly.caixin.com/2016-11-12/101006877.html
- 类型：商业调查
- 主要观察：2016 年公开信后，外界开始系统审视复杂生态、产品扩张、资金链和融资模式。
- 对 Skill 的意义：
  - “复杂模式”可能提高传播势能，也可能降低外界理解度和验证效率。
  - 输出战略时应增加一个问题：**外部投资人/客户能否用简单指标验证？**

## E03 — 2017 第一财经：控制权底线

- 来源：第一财经本人专访
- 链接：https://www.yicai.com/news/5205432.html
- 类型：直接证据 + 可用于反证
- 主要事实：即使处在资金紧张阶段，仍强调七个子生态控制权与整体战略相关。
- 对 Skill 的意义：
  - 这是生态完整性影响真实资本决策的证据。
  - 同时也是“战略完整性可能与短期融资效率冲突”的典型风险样本。

## E04 — 乐视前公关负责人回忆

- 来源：36氪转载/前员工叙述
- 链接：https://m.36kr.com/p/1721970524161
- 类型：前员工回忆，B/C 级辅助材料
- 主要观察：内部不同业务之间实际协同存在困难，与对外“生态化反”叙事之间存在落差。
- 对 Skill 的意义：
  - 必须区分“生态理论”与“组织是否真的完成协同”。
  - 模拟做事方式时，不能只写跨部门协同口号，要指定数据、接口、责任人和共同 KPI。

## E05 — FF 前员工批评材料

- 来源：界面新闻
- 链接：https://www.jiemian.com/article/1771916.html
- 类型：前员工/消息源报道，辅助反证
- 主要观察：管理、融资、产品实现等方面存在尖锐批评，并伴随高管离职和建厂计划变化。
- 使用规则：
  - 不把单个前员工评价当作确定事实。
  - 只用于提醒研究者寻找治理、组织稳定性和工程计划的独立证据。

## E06 — 2019 FF 官方治理调整

- 来源：Faraday Future
- 链接：https://www.ff.com/us/press-room/FF-restructuring/
- 类型：公司正式治理信息
- 主要事实：公司确认组织重组、CEO 职位变化，同时强调互联网生态模式仍被视为长期重要资产。
- 对 Skill 的意义：
  - 组织角色可变化，但“生态/产品愿景”继续保持连续。
  - 应把“角色调整”和“战略信念改变”分开判断。

## E07 — FF 证券文件中的创始人影响力风险披露

- 来源：Faraday Future SEC/投资者文件
- 示例链接：https://investors.ff.com/static-files/2bda4e08-b21e-4706-9f47-8ca421f94d21
- 类型：监管披露
- 主要信息：公司风险披露中明确讨论贾跃亭及相关方对管理、业务和运营的显著影响，以及这种影响可能与公司财务/业务目标存在不一致的风险。
- 对 Skill 的意义：
  - “Founder-led”模型必须同时带治理边界。
  - 高保真模型不能把创始人深度介入无条件视为优势。

## E08 — 2016《环球人物》危机报道

- 来源：人民网《环球人物》
- 链接：https://paper.people.com.cn/hqrw/html/2016-12/06/content_1759295.htm
- 类型：危机阶段人物报道
- 主要观察：公开信后，公司开始强调经营、盈利、末位淘汰和组织调整；报道同时呈现支持者与质疑者对乐视模式的不同判断。
- 对 Skill 的意义：
  - 贾跃亭模式并不是“永远扩张”，危机后也出现过明确的经营导向、效率导向和淘汰机制。
  - 这可纠正“只会烧钱、只会 All In”的低质量 caricature。

## E09 — 2025–2026：从愿景语言转向“股东优先 + 绩效”

- 来源：FF 官方 Co-CEO 讲话
- 链接：https://investors.ff.com/news-releases/news-release-details/faraday-future-announces-company-founder-yt-jia-appointed-co-ceo/
- 类型：本人直接证据
- 主要变化：明确提出 Stockholders First、Performance-Is-King、奖惩分明、财务与合规系统升级。
- 对 Skill 的意义：
  - 最新时期不能只复刻 2015 年的“梦想/生态”。
  - 当前版本应该同时体现资本市场、股东回报、绩效和合规语言。

# 反证检查清单

任何准备写入 `thinking-models.md` 的稳定结论，都要问：

1. 本人至少两个不同年份是否都出现过？
2. 实际行动是否支持？
3. 有没有明确相反案例？
4. 这是贾跃亭特征，还是所有创业公司都会说的话？
5. 这种风格的收益是什么？代价是什么？
6. 2015 与 2026 的表现是否一致，还是已经发生阶段变化？

# 当前最关键的“双面模型”

| 正向模式 | 对应风险 |
|---|---|
| 未来倒推 | 低估当前资源与工程约束 |
| 破界整合 | 组织复杂度与协同成本快速上升 |
| 高信念 | 反证信息可能被弱化 |
| 创始人深度介入 | 治理和授权风险 |
| 里程碑传播 | 容易把计划节点与实际兑现混在一起 |
| 战略叙事连续 | 路径失败可能被反复重新包装 |
| 用户共创 | 若没有真实反馈闭环，可能退化为营销标签 |
| 数字化框架 | 结构清晰，但也可能制造“看起来很完整”的错觉 |

Skill 的目标不是消除这些矛盾，而是**同时保留能力与代价**。
