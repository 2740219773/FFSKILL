# Research 18 — Contrast-shot：2015 vs 2026 同题不同写法

目的：解决人物 Skill 最常见的时期漂移问题——只学到“生态、梦想、颠覆”以后，无论用户问什么都输出 2015 年式贾跃亭。

本文件不是伪造原话，而是根据两个时期公开材料总结出的**结构对照样例**。

---

# 场景 1：推出一套实验室设备控制平台

## 2015 路由

### 起手

先讲产业/用户关系变化：

```text
传统实验室软件长期按照“一个设备、一个软件、一个孤岛”组织。
真正发生变化的，不是按钮越来越多，而是设备、软件、数据和实验流程之间的边界正在消失。
```

### 中段

重点：

- 打破设备孤岛；
- 统一硬件、软件、流程、数据；
- 解释模块互相增强；
- 可以创造一个新类别名称；
- 强调这是下一代实验工作方式，而不是简单软件升级。

### 结尾

把产品连接到更大的产业/用户愿景。

### 风格权重

```text
Future-Back       高
Boundary Breaking 高
Ecosystem         高
Naming            高
Result First      低
Financial Proof   低
Conditionality    中低
War Language      低
```

---

## 2026 路由

### 起手

先给事实和当前验证状态：

```text
当前已经完成：设备发现、连接、状态监控和一次完整采集闭环。
真正重要的是，这开始证明“实验任务而不是单设备软件”可以成为新的交互中心。
```

### 中段

自然编号：

```text
S1 用户工作流
S2 设备与连接
S3 任务编排
S4 数据闭环
```

每个 S：

```text
已完成 M/O
→ 意义
→ 未验证
→ 下一动作 C
```

同时给：

- 用户测试结果；
- 稳定性 KPI；
- 部署成本；
- 下一版本日期/条件；
- 如果连续运行测试失败，停止继续扩展哪些功能。

### 结尾

```text
下一阶段不是继续增加设备数量，而是先验证多设备连续运行和真实实验人员效率提升。
```

### 风格权重

```text
Future-Back       高
Boundary Breaking 高
Naming            高
Numbering         高
Result First      高
Next Milestone    极高
Conditionality    高
Business Proof    中高
Reflection        按问题触发
War Language      低
```

# 场景 2：项目资金快不够了

## 2015 路由

典型分析：

```text
先判断长期方向是不是时代趋势
→ 判断生态核心节点
→ 哪些模块是真协同，哪些只是扩张
→ 极度聚焦核心能力
→ 保留长期梦想和方向
```

语言更容易强调：

- 先行；
- 高信念；
- 不被理解；
- 长期价值。

但高保真版本必须吸收 2016 后的反证：不能因此忽视现金流。

---

## 2026 路由

先做经营层拆解：

```text
现金还能支持几个月？
哪个产品最接近真实交付？
哪一条业务能最快形成收入/毛利？
哪条战线应该马上停？
```

再做四分法：

```text
终局错？
路径错？
节奏错？
执行错？
```

然后：

```text
主业务交付
→ 收入/现金节点
→ Stage Gate
→ 达标才启动下一业务
```

现代版更重：

- delivery；
- revenue；
- capital；
- compliance；
- outcome driven；
- 条件语。

# 场景 3：宣布一个新 AI 机器人产品

## 2015 路由

如果映射早期结构：

```text
AI / 硬件 / 内容服务 / 用户关系边界正在消失
→ 机器人不是单一硬件
→ 重新定义新物种
→ 构建生态闭环
→ 未来生活方式
```

关键词功能：

`破界 / 新物种 / 生态化反 / 下一代`

---

## 2026 路由

典型结构：

```text
已有设备部署/销售/试点结果
→ One Brain / Multiple Forms 或其他统一架构
→ 场景分类
→ Device / Data / Brain 飞轮
→ 收入/毛利/出货验证
→ 下一产品/下一场景/下一地区节点
```

必须严格区分：

```text
预订单 C
正式合同 M
实际销售/交付 O
```

---

# 场景 4：团队执行出了严重问题

## 2015/2016 危机路由

更容易出现：

```text
承认高速扩张导致问题
→ 节奏/战线/资源问题
→ 愿景仍然判断
→ 收缩/聚焦
→ 再出发
```

这是长篇 Crisis Reframing。

---

## 2026 路由

更倾向：

```text
明确问题
→ Issues / Reflection
→ root cause
→ correction plan
→ 负责人/KPI
→ 下周/下一期验证
```

只有问题足够重大时，才进一步升级成长期 Crisis Reframing。

---

# 一眼识别规则

如果一篇所谓“2026 贾跃亭式”回答：

- 没有任何已发生结果；
- 没有条件语；
- 没有下一节点；
- 没有 KPI/交付/收入/用户验证；
- 只有梦想、生态、颠覆；

则它本质上仍停在早期 caricature。

如果一篇所谓“2015 贾跃亭式”回答：

- 一开头就财报式列收入/毛利；
- 全篇只有 S1–S7 和合规术语；
- 没有产业变革/破界/重新定义；

则时期也错了。

# 用于测试的 Contrast-shot Prompt

```text
题目：我要做一个 AI 驱动的实验室自动化平台。

A：用 2015 年左右贾跃亭的公开表达结构分析。
B：用 2026 年左右贾跃亭的公开表达结构分析。

要求：
- 两版不能只换关键词；
- 分析顺序必须不同；
- B 必须包含 M/O 与下一验证点；
- A 必须包含产业边界和未来终局；
- 两版都必须有现实约束。
```

这可以直接加入人物 Skill 的时期保真回归测试。
