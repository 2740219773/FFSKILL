# Research 32 — 非产品型长演讲解剖：2015 深圳 vs 2016 战略/危机

更新时间：2026-09-03

# 一、2015 深圳：像一篇“产业理论论文”，而不是产品发布会

这场面向深圳政府部门的演讲约两小时，本人一开始就把内容明确拆成三大部分：

```text
1. 全球经济和产业发展趋势
2. 互联网生态究竟是什么、乐视如何实践
3. 对全球经济、中国经济和深圳发展的借鉴意义
```

这说明 Numbered Architecture 在正式长演讲中不是装饰，而承担“让听众知道未来两小时去哪儿”的导航功能。

## 1. 第一部分先搭宏观历史坐标

不是从乐视开始，而从：

```text
工业革命
→ 信息技术革命
→ 传统互联网
→ 下一代创新驱动周期
```

再讨论：

- 技术创新；
- 商业模式创新；
- 价值链连接效率创新；
- 下一代互联网需要什么新理论。

典型动作：

> 先把自己的商业实践放进更大历史周期，再把“生态”定义成历史演化的下一阶段。

## 2. 第二部分才把乐视作为“案例”放进来

逻辑不是：

> 我们做得很好，所以理论正确。

而是：

```text
先提出产业理论
→ 再用乐视的平台/内容/终端/应用去说明理论
→ 再解释为什么专业化分工开始失效
```

这种表达方式能让企业战略看起来像“产业规律的实例”，而不是公司自卖自夸。

## 3. 第三部分再上升到国家/城市层级

最后并不是回到产品，而是讨论：

- 中国经济；
- 全球产业格局；
- 深圳的创新机会。

所以完整的长演讲尺度是：

```text
世界
→ 理论
→ 公司实践
→ 世界/中国/城市
```

即一个闭环，而不是“宏大开场 → 公司广告”。

# 二、2015 深圳演讲的核心修辞：专业分工是旧世界

这场演讲对“专业化分工”提出系统性挑战。

其典型推导：

```text
工业时代
→ 专业化分工提高效率
→ 产业边界固定

互联网时代
→ 技术让连接成本下降
→ 用户需求跨越产业边界
→ 价值链连接/跨界协同成为新的创新源
```

这比发布会上的“苹果旧范式”更抽象：敌人不是一家公司，而是一整套经济组织原则。

### Skill 中的使用边界

不能把“专业化分工过时”理解成“专业能力不重要”。

更准确地转译成：

> 专业能力仍需极深，但用户价值的组织方式不应被部门/产业边界锁死。

# 三、2016 年战略会：从产业理论升级到组织共同体

2016 年战略会的公开材料突出：

- 全球化；
- 四维组织；
- 全球顶尖人才；
- 共创共享；
- 蒙眼狂奔；
- 生态世界。

与 2015 深圳不同，听众主要是内部组织，因此叙事重心发生变化。

```text
2015 深圳：为什么世界需要生态
2016 战略会：什么样的组织才能把生态做成
```

## 1. 组织不只是执行容器

在这套话语里，组织本身也是生态的一部分：

```text
打破业务边界
→ 打破部门边界
→ 全球人才跨地域协作
→ 共创共享机制
```

## 2. “蒙眼狂奔”在危机前仍是正向精神词

2016 H1，“蒙眼狂奔”更多指：

- 高速度；
- 不畏未知；
- 自我颠覆；
- 全球扩张。

但到 2016 H2《海水与火焰》，它又变成需要反思的速度失控隐喻。

这是极好的“同一词语随结果改变意义”的案例。

Skill 不应把“蒙眼狂奔”固定定义成正面或负面，而要按时期和结果路由。

# 四、2016 H2 Dream On and All In：危机后重新取得叙事控制

危机后的长演讲结构明显变化。

不再是：

```text
未来必然如此
→ 我们已经站在正确位置
```

而是：

```text
承认第一阶段问题
→ 把问题归入节奏/能力/资金
→ 提出第二阶段
→ 聚焦、P&L、现金流
→ 继续保留生态终局
→ 汽车仍是长期变革梦想
→ Dream On and All In
```

这是一种非常典型的“危机后重建连续性”。

# 五、一个关键差异：长演讲靠什么维持节奏

产品发布会有：

- 新品揭晓；
- 参数；
- 价格；
- 真机；
- 明星/伙伴。

非产品演讲没有这些天然爆点，所以更多依赖：

1. **层级跃迁**：世界 → 行业 → 公司 → 中国；
2. **编号导航**：三大部分、几类创新、七大生态；
3. **旧/新范式对立**；
4. **历史类比**；
5. **反常识判断**；
6. **阶段切换**；
7. **个人/组织使命**。

因此 Skill 如果要生成长演讲，不能只是把短答扩写 10 倍。

# 六、长演讲生成协议

## 2015 理论型

```text
第一章：世界正在发生什么
第二章：旧经济理论为什么不足
第三章：新理论/新竞争单位是什么
第四章：我们的实践如何验证
第五章：这个理论对更大范围意味着什么
第六章：下一轮历史机会
```

## 2016 内部战略型

```text
第一章：外部时代窗口
第二章：我们当前到了哪一阶段
第三章：组织为什么必须跟着战略进化
第四章：几个核心战役/组织机制
第五章：哪些行为是文化要求
第六章：全球化和长期使命
```

## 2016 H2 危机型

```text
第一章：先承认客观问题
第二章：问题发生在哪一层
第三章：什么不变、什么必须变
第四章：新阶段的资源/组织/现金逻辑
第五章：下一证明点
第六章：保留长期使命，但不掩盖现实
```

# 七、对核心 Skill 的新增启发

## 1. Macro-Micro-Macro Loop

长演讲常见：

```text
宏观规律
→ 公司/产品实践
→ 再回到宏观意义
```

这比“一直宏大”更有说服力。

## 2. Theory Before Self-Promotion

高保真贾跃亭长演讲往往试图先证明一个产业规律，再说乐视为什么符合这个规律。

Skill 应优先：

> 先让逻辑即使删除公司名仍然成立。

## 3. Stage Narrative

危机前后都喜欢把历史分阶段：第一阶段完成什么，下一阶段改变什么。

但阶段命名不能抹掉失败事实。

---

# 一句话结论

贾跃亭的长演讲不是“口号特别多”，而是常用：

> **历史周期 → 新理论 → 自身实践 → 更大意义**

构造一个闭环；危机后再把它变成：

> **事实问题 → 阶段切换 → 新机制 → 长期使命**。
