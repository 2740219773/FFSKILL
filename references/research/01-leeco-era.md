# Research 01 — 乐视时期公开材料（2014–2017）

本文件只保存可追溯材料与初步提炼，不直接把单条材料升级为稳定人格结论。引用原话尽量控制为短句，主体使用摘要。

## L01 — 2014-12-09 / SEE 计划公布

- 类型：本人微博经媒体转述
- 阶段：乐视汽车起点
- 来源：中国新闻网 / 新京报
- 链接：https://www.chinanews.com/cj/2014/12-10/6861401.shtml
- 证据：A（媒体完整转述本人微博）
- 核心表述：移动互联网将推动汽车产业发生巨大变化；SEE 计划要复制乐视的垂直整合模式并“重新定义汽车”。
- 行动信息：乐视把汽车从单一制造问题定义为“汽车互联网生态系统”。
- 可提炼特征：
  - 先宣布行业革命，再宣布产品。
  - 从一开始就避免“只造一辆车”的单产品定义。
  - “重新定义”不是后期 FF 才出现，而是汽车项目起点就存在。

## L02 — 2015-01-04 / 新年内部信与年度目标

- 类型：公开内部信/媒体报道
- 来源：中国经济网
- 链接：https://www.ce.cn/cysc/tech/rw/201501/04/t20150104_4255540.shtml
- 证据：A/B
- 核心内容：把未来十年描述为中国产业互联网企业走向全球的重要窗口；将乐视垂直整合模式与全球化绑定。
- 可提炼特征：
  - 常用 5–10 年时间尺度描述眼前业务。
  - 公司动作被放入“中国产业升级/全球竞争”更大框架。
  - 目标通常同时包含收入、产品规模和组织机制（如全员持股）。

## L03 — 2015-05-06 / 《环球人物》长访谈

- 类型：长篇人物专访
- 来源：人民网《环球人物》
- 链接：https://paper.people.com.cn/hqrw/html/2015-05/06/content_1631010.htm
- 证据：A
- 关键短句："这不是乐视的选择，而是时代的选择。"
- 核心观点摘要：工业时代的专业化分工会在互联网时代受到挑战，产业边界会模糊，垂直整合会产生新模式。
- 可提炼特征：
  - 把个人/公司选择外化为“时代必然”。
  - 喜欢使用“旧时代范式 vs 新时代范式”二分结构。
  - 先提出产业规律，再证明自己的模式顺应规律。
  - 对“贪多嚼不烂”的质疑，回答方式不是缩回单点，而是重新定义多业务整合的合理性。

## L05 — 2016-04-20 / “无破界，不生态”发布会

- 类型：产品发布会
- 来源：乐视活动页、媒体报道
- 活动页：https://m.le.com/
- 辅助报道：https://www.sohu.com/a/71911974_120078003
- 证据：A/B
- 关键短句："一切可以破界流动。"
- 核心内容：手机、电视、VR、汽车被放到同一场生态发布会中，强调科技、艺术、互联网融合。
- 可提炼特征：

  - 发布会不以单产品收束，而以跨产业协同收束。
  - 擅长给系统关系起名字，而不是只描述功能关系。

## L06 — 2016-09 / 汽车融资与资金压力表达

- 类型：采访/公开活动
- 来源：中国之声
- 链接：https://china.cnr.cn/qqhygbw/20160905/t20160905_523113037.shtml
- 证据：A
- 核心内容：承认战略模式天然带来资金压力，同时强调“用有限资金投资未来”的价值判断。

- 链接：https://paper.people.com.cn/zgcsb/html/2016-10/24/content_1721643.htm

## L08 — 2016-11-06 / 《乐视的海水与火焰》

- 类型：全员公开信
- 来源：经济观察网
- 链接：https://www.eeo.com.cn/2016/1106/293722.shtml
- 证据：A
- 核心内容：首次系统承认发展节奏过快、全球战线过长、供应链与资金压力；提出告别单纯烧钱扩张、强化经营和盈利。
- 可提炼特征：

  - 典型重构：愿景仍成立 → 执行节奏出错 → 收缩战线 → 开启新阶段。
  - 标题本身使用极强的二元戏剧结构：被巨浪吞没 vs 把海洋煮沸。

## L10 — 2017-01 / 《挣扎贾跃亭》

- 类型：深度人物采访
- 来源：中国企业家 / 新浪转载
- 链接：https://finance.sina.cn/2017-01-04/detail-ifxzczsu6754845.d.html
- 证据：A + 外部观察 B
- 本人表达摘要：危机已解决较大部分；最困难阶段已经过去；乐视理念、基因、精神不会改变。
- 媒体观察：受访者反复把乐视视作其个人性格的集中体现，描述出“巨大野心与现实资源不匹配”的张力。
- 可提炼特征：
  - 即使处于危机，仍保持很高确定性。
  - 喜欢把组织价值观称为“基因”，意味着战略并非普通可替换方案，而是身份的一部分。
  - 需要同时保留第三方对资源错配的反证。

## L11 — 2017-01 / 第一财经专访

- 类型：电视独家专访
- 来源：第一财经
- 链接：https://www.yicai.com/news/5205432.html
- 证据：A
- 核心观点：财务上可以出让更多股权，但七个子生态的控制权不能轻易放弃，因为控制权关系整个生态战略。
- 可提炼特征：
  - 对生态协同的要求会进一步影响资本结构和控制权选择。
  - 战略完整性优先级很高，甚至在资金紧张时也不愿轻易切割。
  - 这是“生态逻辑如何进入真实决策”的高价值案例。

## 阶段结论（暂定）

2014–2017 至少可以确认以下跨场景稳定特征：

1. **先定义时代，再定义公司动作。**
2. **持续用“旧范式 → 新范式”重构问题。**
3. **跨边界整合被视为价值来源，而不是管理负担本身。**
4. **愿景和公司身份高度绑定，路径失败时优先修正节奏而非否定终局。**
5. **高确定性、高投入和资源约束长期存在张力。**

这些结论后续需要与 FF 2017–2026 材料交叉验证。
