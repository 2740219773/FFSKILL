# Case 1 — 2014 超级电视：目标上调后基本兑现

## C — 初始目标

2014 年内部年度目标约为 100 万台超级电视。

2014 年中，本人接受采访时称因为销售超预期，年度目标上调至 150 万台。

## O/M — 后续结果

乐视网后续公司材料披露：2014 年超级电视累计销量突破 150 万台。

### 研究意义

这是一个重要正例：

```text
高目标
→ 需求超预期
→ 上调目标
→ 供应链/产能承压
→ 公司披露达到目标量级
```

因此 Skill 不能把其所有高确定性目标都视为“叙事而非执行”。

### 但要保留的风险

2015 年投资人交流里，本人也回顾：2014 销量从原估 100 万增长到约 150–160 万，反而暴露屏幕预测和资金准备不足，产能受到影响。

即：

> **销量目标成功 ≠ 运营系统没有问题。**

成功本身也可能制造供应链压力。

# Case 2 — 2015 超级手机：首年目标超额

## C — 市场蓝图

2015 年中，财新报道乐视对部分投资人给出的手机蓝图是：

- 2015 年约 300 万台；
- 2016 年约 1000 万台。

## O — 2015 结果

2016 年 1 月乐视移动公开称：2015 年全年销量超过 400 万台，超过年度目标。

人民网等媒体记录了这项公司公布数据。

### 研究意义

超级手机第一年是另一个“高目标确实阶段性兑现”的案例。

这说明人物模型里应区分：

```text
新产品早期规模化能力
vs
整个生态长期财务可持续性
```

前者在电视、手机早期存在真实成绩；后者不能由销量自动证明。

# Case 3 — 2016 手机：规模目标接近兑现，但现金/供应链恶化

## C — 2016 目标

2016 年初，乐视移动将国内销量目标定为 1500 万台（另有后续更激进的 2000 万级目标/规划报道）。

## M/O — 规模里程碑

- 2016-05：公司宣布超级手机累计总销量突破 1000 万台；
- 2016 年末：乐视移动公司公布全年销量“逼近 2000 万台”。

这些属于公司公布口径，应注明来源属性。

## 同期反结果

2016 年下半年：

- 手机供应链付款压力出现；
- 本人公开承认手机业务存在欠款/供应紧张问题；
- 资金与资源不足成为集团危机的一部分。

### 最重要的研究结论

这是整个项目非常好的反例：

```text
销量 KPI 可以达到/接近达到
≠ 现金流健康
≠ 供应链健康
≠ 商业模型已经闭环
```

因此现代 Skill 如果只追“规模结果”，仍可能重复早期问题。

### 必须增加指标

任何增长型项目至少同时看：

```text
销量/用户数
+ 单位毛利
+ 现金转换周期
+ 应付账款
+ 库存
+ 续费/LTV
```

# Case 4 — 超级电视：规模增长与硬件盈利模式调整

早期超级电视主张低硬件利润，以内容/广告/应用等多重收入实现生命周期价值。

到 2016–2017 危机期间，电视业务管理层开始强调：

- 逐渐减少硬件亏损；
- 提升生态运营收入；
- 追求更强 P&L 和现金流。

### 研究意义

商业模型本身没有简单从“对”变“错”，而是现实约束改变了最优补贴强度。

这支持一个动态启发式：

```text
早期抢入口
→ 可以接受可控补贴

规模形成后
→ 必须逐步提高单位经济性
```

不能把“硬件免费”当永久原则。

# Case 5 — 汽车：2018 量产目标长期延后

## C — 2016/2017 公开目标

2016 年 12 月完整访谈里，本人表示汽车量产预期在 2018 年。

2017 年赴美专注汽车时，公开报道仍提到尽快实现 FF91 在 2018 年量产。

## 后续结果

FF91 并未在 2018 年实现原目标意义上的量产交付。

后续经历多年融资、工厂、组织和工程调整，直到 2023 年才出现：

- 首台量产车下线；
- 第一阶段外部用户交付。

详见 `references/research/02-ff-2017-2023.md`。

### 研究意义

汽车案例与电视/手机形成鲜明对照：

```text
软件/内容/消费电子跨界
→ 乐视早期曾快速拿到产品/销量里程碑

汽车
→ 工程、认证、供应链、资本强度远高得多
→ 早期时间承诺严重低估复杂度
```

因此不能从“电视/手机跨界成功很快”外推：

> 跨界能力足以压缩任何行业的工程周期。

# Case 6 — 2016 资金危机：三四个月恢复正常的承诺

## C — 公开判断

2016 年 12 月访谈中，本人称资金危机已解决约 60%–70%，接下来三四个月会恢复正常。

## 后续

2017 年 1 月融创约 150 亿元战略投资落地，短期确实获得大规模资金支持。

但到 2017 年 6 月，本人仍在股东大会上称财务危机教训惨痛，并表示融资到账后的资金安排未达预期；7 月前后危机继续恶化。

### 研究意义

这是典型的：

```text
融资 Milestone 发生
≠ 系统性现金问题已经解决
```

大额融资只能证明资金进入，不能自动证明：

- 资金结构合理；
- 关联往来解决；
- 经营现金流转正；
- 各业务都恢复正常。

# 六个案例带来的“承诺可靠性分层”

人物承诺不能只按“他说话风格”评价，而要按项目类型分层：

## 类型 A：短产品周期、已有相邻能力

例如早期超级电视/手机。

特点：

- 产品周期相对短；
- 可借成熟供应链；
- 原有互联网/内容能力可迁移；
- 销量可以快速验证。

历史上存在较强阶段兑现能力。

## 类型 B：规模目标

可能快速做到数量，但必须同时检查单位经济性和现金周转。

## 类型 C：资本/组织修复

单次融资或重组不等于系统恢复。

## 类型 D：长周期硬科技/重资产

例如汽车。

早期公开时间表明显过于乐观，应大幅提高不确定性权重。

# 对 Skill 的新规则：Commitment Confidence Router

当用户要求用该人物风格制定时间表时，先按类型降低/提高置信度。

```text
相邻产品创新
→ 可给较强目标，但保留供应链 Gate

新市场规模化
→ 目标 + 单位经济/现金 Gate

组织/资金修复
→ 只能按阶段结果，不允许一句“恢复正常”概括

跨产业硬科技
→ 时间承诺自动降低置信度，拆技术/认证/产线/供应链/资金里程碑
```

尤其禁止：

> 因为创始人在电视/手机上曾快速成功，所以汽车/机器人也一定能压缩周期。

不同工程复杂度必须重新估算。

---

# 一句话结论

国内乐视时期最值得学习的不是“高目标都不可信”，而是：

> **同一个高信念人物，在相邻能力、消费电子规模化上可以很快兑现部分目标；但当复杂度跨到重资产硬科技或系统性财务修复时，原来的乐观时间感会严重失真。**
