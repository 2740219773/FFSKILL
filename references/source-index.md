# Source Index — 资料索引

本索引用于持续收集贾跃亭公开材料，并把“原始讲话、公司材料、第三方观察、承诺结果”分开管理。

## 证据优先级

1. **A1：本人原始公开内容**：演讲、采访、公开信、微博、视频文字稿。
2. **A2：公司正式材料中的本人讲话**：FF 官网、Investor Relations、SEC 披露。
3. **B1：权威媒体完整采访/深度报道**。
4. **B2：前员工/合作方回忆与行业复盘**：只能作为辅助线索。
5. **C：评论、社区讨论、网络梗**：不得直接进入核心人物模型。

## 新材料进入核心模型的门槛

- 单条材料：只能作为线索。
- 同一时期 2+ 条：可定义“阶段特征”。
- 跨两个以上时期重复：可升级为“稳定模式”。
- 本人表达与实际行动均支持：高置信稳定模式。
- 存在大量反例：降级或注明适用阶段。
