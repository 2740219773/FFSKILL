# Source Index — 资料索引

本索引用于持续收集贾跃亭公开材料，并把“原始讲话、公司材料、第三方观察、承诺结果”分开管理。

## 证据优先级

1. **A1：本人原始公开内容**：演讲、采访、公开信、微博、视频文字稿。
2. **A2：公司正式材料中的本人讲话**：乐视正式员工信、FF 官网、Investor Relations、SEC 披露。
3. **B1：权威媒体完整采访/深度报道**。
4. **B2：前员工/合作方回忆与行业复盘**：只能作为辅助线索。
5. **C：评论、社区讨论、网络梗**：不得直接进入核心人物模型。

# 新材料进入核心模型的门槛

- 单条材料：只能作为线索。
- 同一时期 2+ 条：可定义阶段特征。
- 跨两个以上时期重复：可升级为稳定模式。
- 本人表达与实际行动均支持：高置信稳定模式。
- 存在大量反例：降级或注明适用阶段。

当前研究权重应保持平衡：

```text
2014–2016 国内乐视源头
≈ 2017–2023 FF 长周期
≈ 2024–2026 现代经营演化
```

不能因为现代材料更容易获取，就让近两年的话术覆盖人物十余年的真实演化。

研究核心原则：**先积累事实，再提炼模式；先保存反证，再做人物模拟。**
